# 运镜词典

一次只选一条。运镜是**句子里的动词**，不是装饰：它决定了观众在这一秒被要求看哪里。

## 一镜一运镜（硬规则）

- **一镜只能有一个主运镜**。同时推 + 摇 + 移 = 模型只执行前半段，后半段变成漂移。
- **相邻镜不得反向**。上一镜右移、下一镜左移，观众立刻感到"跳"。需要反向时，把切点做成遮挡、过肩或特写插入。
- **位移超过画面 1/4 就拆镜**。人物横穿大半画面还要求一个连续跟拍，成品必然糊。
- **能不动就不动**。锁定机位是最被低估的选择，尤其当表演本身够好的时候。
- **写终点不写方向**。"从腰部高度缓推至面部，匀速，到脸前 0.2 秒减速停住" 可执行；"推进" 不可执行。

### 急推 / Punch-in

- 动作：机位不动，焦段在 6–11 帧内从全景等效急变到特写等效（如 24mm → 85mm 观感），落幅锁定目标；中心点在切换过程中同步收拢到目标。
- 参数：切换 6–11 帧；目标 zoom 倍率 2.4–3.8；落幅前预留 ≥10 帧建立全景、落幅后 ≥15 帧读特写；带运动模糊只包住切换段。
- 禁用：一镜一次以上；角色对话段；抒情/回忆段；以及"急推 + 震屏"同时用（读成穿帮）。

### 陡倾滑行 / Steep-tilt glide

- 动作：机位沿倾斜方向匀速滑动，画面地平线在滑动过程中逐渐由正变斜（或由斜变正），终点停在一个刻意歪的构图。
- 参数：滑动 1–3 秒；倾角终点 8–25°；速度恒定不加减速；建议 24–35mm。
- 禁用：一镜内来回倾；与环绕叠加；需要观众读地理关系的建立镜头。

### 顶拍俯冲 / Overhead dive

- 动作：机位从与主体同高下降到接近 90° 垂直俯视（或反向从顶拍下降），过程中主体在画面里的投影位置保持不动。
- 参数：1.5–4 秒；起始仰角 0–10°、终点 75–90°；焦段 24–35mm；需明确主体在落幅中占画面高度百分比。
- 禁用：多人同时移动的场面（俯冲后分不清谁是谁）；没有地面纹理可读的纯色地面。

### 空间穿行 / Space traverse

- 动作：机位沿一条可画在地图上的路径连续前进，穿过一个以上的空间层级（门→走廊→房间），中途不切。
- 参数：3–8 秒；前进速度 0.6–1.2 m/s；焦段 18–28mm 给纵深；路径上至少两个遮挡物被打穿。
- 禁用：模型不擅长保持通道几何；单条 clip 超过 6 秒后墙体必然变形，超过就拆两段并在门框处切。

### 擦脸巡回 / Graze-face tour

- 动作：机位绕主体做小半径弧线，最近处几乎贴到脸部轮廓，前景遮挡物在弧线中途掠过画面。
- 参数：0.8–2.5 秒；半径 0.4–0.8 m；角度 30–90°；焦段 35–50mm；必须指定旋转方向。
- 禁用：需要看清全身动作的镜；主体还要在弧线里做大幅位移（两者互斥，必拆）。

### 张力机位 / Tension camera

- 动作：机位固定在比主体低或高的异常高度，长时间不动，只有极小幅度的呼吸式浮动（< 画幅 2%）。
- 参数：4–10 秒；浮动幅度 0.5–2%；焦段 40–85mm；全程一个构图。
- 禁用：动作段；需要交代空间的全景；与"在等待中发生事件"的镜（那要真动，不能只是抖）。

### 景深分层 / Depth-layer move

- 动作：机位横向平移，让前景、中景、背景三层以不同速度错位（前景扫过最快，背景几乎不动），主体始终在中景。
- 参数：1–3 秒；横移 0.5–2 m；焦段 50–85mm 压缩层次；光圈 f/2.0–f/2.8 保证层次可辨。
- 禁用：背景没有层次可用的空景；主体与背景距离 < 1 m（压不出分层）。

### 手持微调 / Handheld micro

- 动作：无位移，只有幅度 < 10 cm 的持续微幅晃动，模拟手持呼吸；偶尔一次重新构图（reframe）而不是甩镜。
- 参数：全程持续；幅度 < 10cm；每次 reframe 位移 < 画幅 10%；焦段 25–50mm。
- 禁用：写成"手持晃动"就完事——必须同时点明"小幅度微调，不是晃动"；需要精确构图的对称镜。

### 环绕 / Orbit

- 动作：机位绕主体做 90–360° 圆弧运动，半径固定，主体始终在画面中心。
- 参数：2–6 秒；半径 1.5–3 m；焦段 35–50mm；必须指定方向与是否收尾停在正面。
- 禁用：一镜内环绕超过 180°（超过后背景必然崩）；需要看清背景地标的镜。

### 升降 / Crane

- 动作：机位垂直升降，落幅揭示或隐藏环境信息（升高揭示全景，降低进入人物视线高度）。
- 参数：1.5–4 秒；升降 0.5–3 m；焦段 24–50mm；必须写清落幅要揭示什么。
- 禁用：落幅没有新信息可揭示（纯粹为了动而动）；室内低层高空间。
