## 成像底层
- 数字采集模拟低反差自然光胶片；整体曝光正常偏亮半档
- 颗粒强度区间：`[低, 低]`，几乎无颗粒
- 高光滚降：极柔，阳光直射处过曝只变淡不结块，`[1档, 2档]`
- 暗部：**不死黑**，暗部偏暖棕，0 值裁剪 `[≤3%]`

<!-- slice:story shot prompt -->
## 形体与骨相
- 头身比区间：`[6.5, 7.5]`，写实
- 真人骨相，日晒质感：颧骨与手臂有晒痕，皮肤纹理真实
- 衣料：棉麻、旧牛仔、粗针织；起球、褪色、接缝可见

<!-- slice:shot prompt assets -->
## 影调与光比
- 光比区间：`[1:2, 1:4]`
- 色温区间：`[4300K, 6000K]`，自然天光为主，黄昏偏金
- 光源动机：天光、窗光、篝火、油灯；光源永远可解释
- 全画面低反差，无戏台式打光
- 禁止硬光切边、禁止影棚轮廓光、禁止夜景霓虹

<!-- slice:shot prompt assets -->
## 色彩命题
- 主调大地暖色：沙、麦、土、砖，占画面 `[50%, 70%]`
- 辅调草绿与灰蓝（天空与植被），小面积
- 饱和度区间：`[中, 中]`，肤色温润不橙
- 色值（源自 20 位大地暖调导演的真实聚合）：`#D2A573` 沙金 · `#E8D4B5` 麦白 · `#8D704A` 土棕 · `#314332` 松绿 · `#D28B44` 落日橙 · `#6C8C98` 远山蓝
- 禁止青橙模板、禁止冷调打底、禁止荧光色

<!-- slice:shot prompt assets -->
## 空气与介质
- 介质层数：`[2, 4]` 层——尘、热浪、薄雾、空气透视
- 空气透视：远景饱和降 `[15%, 30%]`，明度提 `[10%, 20%]`
- 风：草、麦、衣角同向摆动 `[5°, 15°]`
- 禁止体积光柱、禁止烟饼

<!-- slice:shot prompt assets -->
## 光学与镜头
- 焦段区间：`[24mm, 85mm]`，风光用 `[24mm, 35mm]`
- 景深：`[f/2.8, f/8]`，中深景深，前后景都可读
- 畸变：`[24mm, 28mm]` 允许 `[0.5%, 1%]`
- 滤镜：无；禁星芒、禁重光斑
- 快门：正常速度

<!-- slice:prompt assets -->
## 材质响应
- 金属：农具与铁皮哑光锈迹，反射值 `[0.2, 0.4]`
- 织物：棉麻吸光，晒褪处偏白，褶皱硬
- 皮肤：日晒红棕，高光为汗的细光，`[1mm, 2mm]` 次表面暖渗
- 土地：干裂有裂纹，湿处深一档

<!-- slice:shot prompt -->
## 特效语言
- 允许：尘土飞扬、草浪、炊烟、逆光轮廓（浅）
- 禁止：粒子、光阵、辉光滤镜、镜头光斑

<!-- slice:prompt -->
## 针对性禁项
1. 青橙电影感模板：暗部推青破坏暖底
2. HDR 阴影提亮：天空死白、地面全亮
3. 苦难滤镜：把贫困做成脏与灰
4. 霓虹或城市冷光：出现在这个调子里即穿帮
5. 高饱和旅游海报色：麦田绿到荧光
6. 逆光金边滥用：每人头发都发光
7. 影棚质感人像：背景虚化成奶油
