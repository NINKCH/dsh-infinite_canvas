## 成像底层
- 三渲二水墨：3D 立体骨相 → 渲染后叠加宣纸肌理、枯笔描边与墨韵
- 颗粒/纸纹强度区间：`[中, 高]`，宣纸纤维与墨粒沉淀可见
- 高光滚降：硬，`[0.5档, 1档]` 内由墨黑直切留白，不用柔化
- 暗部：**允许焦墨死黑**，焦墨块不超过 `[20%, 35%]`，块内保留笔触

<!-- slice:story shot prompt -->
## 形体与骨相
- 头身比区间：`[7.0, 8.0]`
- 立体骨相 + 水墨轮廓：颧骨与肩胛有体积，但外轮廓由枯笔飞白断线构成
- 非写实真人；五官用墨线提点，眼白留纸白
- 衣料：宽袍大袖，用大块墨面概括，褶裥以飞白夹缝表现，垂坠感来自重力方向而非贴图

<!-- slice:shot prompt assets -->
## 影调与光比
- 光比区间：`[1:5, 1:10]`
- 色温区间：`[3800K, 6500K]`，墨色本身中性，冷暖只由朱砂与金点缀
- 光源动机：天光、月光、刀气自发光、烛火
- 明暗靠墨阶：五阶墨（焦、浓、重、淡、清）分明，阶与阶之间不做渐变
- 禁止柔光满铺、禁止三维均匀打光

<!-- slice:shot prompt assets -->
## 色彩命题
- 主调五阶墨 + 宣纸米白
- 辅调朱砂、石青、赭石，占比 `[5%, 15%]`
- 饱和度区间：`[低, 中]`，朱砂可到 `[高, 高]` 作唯一重音
- 色值：`#12100E` 焦墨 · `#3A3733` 浓墨 · `#7A756C` 淡墨 · `#C0452F` 朱砂 · `#EFE7D6` 纸白
- 禁止荧光色、禁止赛博青紫、禁止彩色渐变光效

<!-- slice:shot prompt assets -->
## 空气与介质
- 介质层数：`[2, 4]` 层——墨雾、飞白尘、留白气口、水痕
- 墨雾：用泼墨块面表达，边缘有笔锋与飞溅 `[2, 4]` 处
- 留白：画面留白占 `[20%, 40%]`，留白处不填任何细节
- 水痕：墨向下渗流，末端渐淡
- 禁止 3D 体积雾、禁止真实丁达尔光柱

<!-- slice:shot prompt assets -->
## 光学与镜头
- 焦段区间：`[28mm, 100mm]`，武戏用广角压迫，对峙用长焦压缩
- 景深：虚拟，靠墨阶与细节密度分离前后景
- 桶形畸变：允许 `[1%, 2.5%]`，用于冲击镜头
- 滤镜：无真实滤镜；可叠宣纸纹与墨点
- 禁止失焦光斑、禁止镜头污渍

<!-- slice:prompt assets -->
## 材质响应
- 金属：刃口留白成一道亮线 `[1px, 3px]`，刀身用浓墨渐层，不反射环境
- 织物：麻布用干笔扫出织纹，丝绸用淡墨湿笔，褶皱边缘飞白断裂
- 皮肤：淡墨渲染 + 纸白高光，`[2, 3]` 阶，不做油光
- 玉石：石青石绿薄罩，半透靠留白，不做真实折射与内部纹理

<!-- slice:shot prompt -->
## 特效语言
- 允许：狂草墨韵刀气（笔锋可辨、有起收笔）、墨点飞溅、泼墨扩散、朱砂印章式点睛
- 允许：单帧墨块爆散、笔触拖尾 `[3, 6]` 帧
- 禁止：发光法阵、能量对波、写实火花、彩色粒子
- 禁止：墨效糊住五官，禁止全身包描边光

<!-- slice:prompt -->
## 针对性禁项
1. 水墨做成灰阶照片：只有灰调没有墨阶与纸纹
2. 描边均匀：全身一圈等粗黑线
3. 3D 塑料感：高光圆润发亮
4. 墨块糊脸：五官被泼墨盖住
5. 留白填满：画面无气口，全是对称细节
6. 彩色水墨：青紫渐变光效当墨
7. 笔触方向乱：飞白不顺着结构走
8. 写实粒子：真实爆炸与火星出现在水墨里
9. 朱砂泛滥：红色铺满画面抢主体
10. 景深造假：背景高斯模糊，纸纹一起糊
11. 光影均匀：没有明暗交界，只有平灰
