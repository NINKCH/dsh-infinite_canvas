# 创作方法论（剧本 / 分镜 / 提示词）

本技能是**创作手法**规范；画布的操作流程（建项目、写节点、触发生成）见 `canvas-studio`。
两者配合使用：先按本技能写出合格内容，再按操作规范落到画布上。
本技能里的「硬规则 / 判定口径」**优先于任何专家人设的一句话概括**（人设只给方向，本技能给可核对的判据）。

## 一、短剧剧本方法论

### 结构与节奏
- **单集时长**：竖屏短剧常见 60–120 秒；对应 **4–8 场**，每场 15–30 秒。
- **开场 10 秒必须有钩子**：悬念、冲突、反常画面或一句扎心的台词；不要铺垫世界观。
- **三段压缩**：建置（1–2 场）→ 对抗（主体，冲突升级）→ 解决/反转（1 场，留悬念）。
- **每场一个小目标**：人物想要什么 → 遇到什么阻碍 → 结果如何转折。写不出这条，这场就该删。
- **结尾留钩子**：最后 3–5 秒抛出新信息或未解之谜（下集驱动力）。

### 场景间因果钩子（连贯性硬规则，缺这条剧本就是流水账）

**每场结尾必须留一个"推动下一场的具体东西"**：一个动作、一件物件、一句没说完的话、一个刚被揭开的动作结果。
它是下一场的**起因**，不是本场的**总结**。

- ✅ 正例：`【场2】他撕开信封，里面只有半张车票。他抓起外套冲出门。` → 场3 由「车票」和「冲出门」引发。
- ❌ 反例：`【场2】他感到事情越来越复杂，心里很不安。` → 情绪总结，下一场无从接起。

判定口径：

- **该做**：结尾句必须是**可拍摄的动作或可见的物件状态**（手、门、屏幕、脸、道具）；下一场第 1 个动作/画面**直接由它引发**。
- **不该做**：不写"他决定了""事情还没结束""危机正在靠近"这类总结；不用"第二天""与此同时"硬切到毫无因果的新场景。
- **禁止并列场景清单**：每场必须**改变人物的处境或认知**（有变化才成立）；只是"又发生一件事"的场，删掉或合并。
- **四要素每场各至少一处**：**目标**（这场要拿到/守住什么）→ **阻碍**（谁/什么挡住）→ **转折**（计划失效的瞬间）→ **代价**（他为此失去或付出什么）。四者缺一即视为该场不合格。

### 分场格式（固定八要素）
```
【第 N 场】内/外景 · 地点 · 时间
人物：A、B
画面：可拍摄的动作与环境（不写心理活动）
对白：
A：口语化短句。
B：……
```
- **只写能拍出来的东西**：摄影机拍不到的心理描写一律改成动作、表情或对白。
- **对白**：短句、口语；单场不超过 6 个来回；避免解释性台词（"你知道的，当年……"）。
- **一致性**：人名、地名、道具名与设定集**逐字一致**，禁止擅自改名或新增设定。
- **输出格式**：直接给可用剧本正文，不要解释、不要提纲、不要"待生成"占位。


## 二·五、资产设定图版式（角色/道具/场景的专业排版，拒绝简单三视图）

简单三视图信息量不足——设定图要做成**专业设定集排版**：主图 + 特写 + 表情/色卡分区呈现，
一图读懂资产的全部视觉设定。**版面里绝不渲染成段文字**：文字渲染型模型画长文本必然乱码（实测），
面板文字只允许 ≤4 字短标签（面板名 / 表情名 / 颜色名）。同一资产在所有分格中外观**完全一致**——
**已连接参考图时，参考图形象是唯一事实**，逐格严格复制；未连接参考图时逐格复用设定集外观关键词。

### 角色设定图（16:9 横版——按「六段式」结构写提示词，实测出图最稳）

提示词按以下六段组织，**方括号段名照写**（模型对显式分段结构的遵循度显著更好）：

- **【总起】**一句话交代：16:9 横版专业设定集排版、深色简洁背景、风格基调（如 写实电影感）、
  同一角色在所有分格中外观完全一致。
- **【身份锚】**声明参考图是同一角色的真实照片：严格保持脸型 / 眼型 / 耳形 / 毛量 / 口鼻比例 / 体型，
  只改变姿势与视角；**忽略照片里的临时配饰**（狗绳、挂牌等），配饰一律按提示词文字描述绘制。
  绑定几张参考图就写几个 [图N]。
- **【主体】**中央大幅全身立绘（正面站姿）：体型写量化并加反例（如「约 3 公斤、肩高 20 厘米；
  不是中型犬，不是萨摩耶/银狐/柴犬」——易混淆品种必须显式排除）、毛色毛发、五官、四肢尾巴，
  以及固定配饰的完整描述。**并声明姿态是自然空手站立**：四肢自然着地 / 下垂，口部闭合或自然吐舌，
  **不抱、不拿、不叼、不踩、不坐任何外物**。
- **【主图下方·三视图（必须项）】**正面／侧面／背面三格全身站姿——同一角色只换角度，
  交代侧背形态（后续视频一致性靠它）。
- **【右侧窄栏·自上而下分块；每块内容全图只出现一次】**
  ① 脸部特写一格 + 一行 ≤12 字的五官短标注；
  ② 配饰格（有固定配饰时）：正 / 背两张小图并排，可刻短字，并注明「该物在本图内只出现这一处」；
  ③ 表情格：6 个头部小头像分两行（每行 3 个），每个下方只标两字表情名。
- **【文字规则】**图内文字极少：只保留两三个字的短标签，黑色细体、笔画清楚、字要写大；
  不写任何大标题、说明段或长句。
- **【画面白名单】**反幻觉白名单，逐类点名，实测能压住乱入元素：
  「画面中**只有这一只角色本体与它的固定配饰**（如 项圈 / 挂牌），以及上述分格内容；
  **没有任何被抱、被拿、被叼、被踩或被坐着的物品**——纸箱、包裹、篮子、玩具、食物、乐器、器材、
  道具、家具一律不出现；没有人物、没有其他动物、没有场景陈设、没有文字水印。」

要点：**每块内容全图只出现一次**（配饰在配饰格画过，主图描述就不再重复强调它）；
**外物是最常见的乱入**（"抱着纸箱""叼着玩具""踩着道具"），必须在【主体】声明空手姿态、
并在【画面白名单】里逐类点名排除；反例约束同样有效——易混淆的品种 / 风格务必写进【主体】的排除句。

### 道具设定图（横竖皆可——按道具特性选，不限制）
- **画幅选择**：长条形/单件道具（剑、箫、杖）竖版更能展示完整形态；
  组合道具、带场景感或横向结构的道具用横版能并列更多细节与色卡——排版逻辑不变，画幅自由。
- **顶部**：道具名大标题（≤6 字）。
- **中央主图**：道具斜 45° 悬浮展示，带氛围光/粒子效果，占画面主体。
- **细节特写 2–3 格**：材质纹理、关键部件，格内无文字。
- **侧栏侧视图**：同一道具的正侧面完整形态。
- **底部颜色参考**：3–5 个圆形色卡，每个下方标注颜色名（≤3 字，如「赤红 / 熔金 / 绛紫」）。
- **禁止**：铭文 / 短诗 / 说明文字渲染（易成乱码）。

### 场景设定图（主场景图 + 环绕补充小图）
- **主场景图占画面主体**（全景建立镜头，交代空间结构与光线方向）——不要切成几张等大的长条格，
  那样每格都是局部长图，场景信息反而看不全。
- **环绕补充小图（3–6 张，位置与数量不拘）**，参考版式：
  - 右侧一列：**多角度图**（俯瞰、贴地、第一人称视线等其他机位）+ **其他时间图**（夜景 / 雨雾 /
    逆光等不同时间段或天气下的同一场景）；
  - 底部一排：**细节格**（标志物 / 入口 / 材质纹理 / 关键道具在场景中的位置）。
- 每张小图下方一行**短标注（≤6 字**，如「入口·夜」「雨中·逆光」）。
- 上述布局是大致参考、不强制；所有格子的光线方向、天气、色调须与主图统一
  （展示不同时间段时在标注中说明）。
- **禁止**：成段说明文字。

### 画面感要点
- 用一个**具体的可视细节**替代形容词：不写"他很悲伤"，写"他把没送出的信折了三次，塞回口袋"。
- 每场至少一个"能被记住的画面"（记忆点）。

## 二、分镜拆解方法论

### 粒度
- **一段连续的动作节拍 = 一个镜头**；不要把两个不相关的动作塞进一个镜头。
- **单镜头按时长谱系取值**（见下）；各镜时长之和 = 目标视频总时长，**按内容写足、不设硬上限**
  （如 15 秒 ≈ 4–7 镜，30 秒 ≈ 8–14 镜）。整个分镜表会组合成**一条多镜头提示词，由视频模型一次性生成整段视频**
  （镜头间由模型硬切，不需要逐镜生成再拼接）。
- 一场通常拆 4–8 镜：建置镜（环境/全景）→ 主体镜（中近景）→ 情绪镜（特写）→ 动作镜（跟拍/推拉）；
  镜越短节奏越快，每镜的提示词要越聚焦。
- **每场至少 1 个大特写（短场也不例外）**：用在关键信息或情绪爆点——眼睛、手、纸条上的字、钟表指针、
  扣扳机的手指、屏幕上的名字。`visual` 里写清「大特写 + 拍的是哪个局部」，`duration` 给 0.8–2s；
  一场没有大特写的分镜表 = 没有信息焦点，退回重拆。

### 节奏谱系（时长为情绪与节拍服务，**拒绝均匀分布**）
| 镜头类型 | 时长 | 用途 |
|---|---|---|
| 快速冲突 / 打斗 / 追逐 | **0.3–0.8s** | 快切、追逐、冲突爆发 |
| 重要反转 / 冲击 / 卡点 | **1–2s** | 反转、关键瞬间 |
| 普通叙事 / 对话 / 环境交代 | **2–4s** | 日常推进 |
| 长镜头情绪沉淀 | **≥5s** | 情绪酝酿、氛围、一镜到底 |

- **同一场至少制造一次明显的节奏变化**（例：3s 叙事 → 0.6s 快切×2 → 1.5s 反转 → 5s 情绪长镜）——
  时长全部一样就没有节奏感，画面再精致也不行。
- **快切镜头的提示词要极短**（一个动作、一句画内信息）；信息量大的镜头才配长时长——时长与内容量必须匹配。
- duration 支持一位小数（0.6、1.5 都合法）。

### 情绪 → 景别（根据情绪选景别）
| 情绪 | 景别 |
|---|---|
| 孤独 / 绝望 / 宏大危机 | 远景 |
| 对峙 / 动作 / 关系建立 | 全景 |
| 对话 / 试探 / 信息交换 | 中景 |
| 震惊 / 怀疑 / 内心动摇 | 近景 |
| 崩溃 / 嘶吼 / 情绪爆发 | 特写 |
| 关键细节 / 道具揭示 / 伏笔 | 大特写 |

口诀：**冲突用全景，揭秘转近景，爆发给特写，反转可拉远**；
镜头距离的变化本身在讲情绪：拉开距离 → 进入内心 → 强烈冲击 → 重新审视。

### 剧情四阶（场景内部弧线，也是单集结构）
1. **冲突出现**：常态被打破；
2. **信息升级**：真相推翻旧认知；
3. **情绪爆发**：积压矛盾总爆发——这里是全片节奏最快处（快切 + 特写）；
4. **结局反转**：意料之外，伏笔回收（可拉远收束）。

### 术语表
- **景别**：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写（极致特写：只拍眼睛、嘴、道具细节）。
- **运镜**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 甩 / 升降 / 环绕 / 变焦；**一镜只用一种运镜**。
- **调度**：人物走位 + 机位运动 + 镜头切换的**组合设计**（不是单个动词）；一场戏的调度要回答
  "人往哪走、镜头在哪跟、下一刀切到哪"。
- **高级运镜（按需选用）**：希区柯克变焦（推拉+变焦的眩晕感）、低角度仰拍（英雄感）、
  快速摇镜/甩镜（运动模糊）、手持晃动（纪实不安感）、FPV 第一人称主观（需要连续运动的环境才成立）、
  航拍俯冲（要有明确落点，否则画面漂浮）、机械臂跟随（多角度贴视线）。

### 术语勘误（生成与改写时一律按右列，不要沿用左列口语）

| 常见误写 | 正确写法 | 说明 |
|---|---|---|
| 大豆、大特、特镜 | **大特写** | 只拍局部细节（眼睛、手、字迹、指针），不是"很大的特写" |
| 调职、调道 | **调度** | 人物走位 + 机位运动 + 切换设计的组合 |
| 推近 / 拉远 / 平移（单独使用） | **推镜 / 拉镜 / 移镜**，并写清起点与终点 | 单个动词是空模板，见「motion 公式」 |
| 镜头、画面（当景别用） | **具体景别**（大特写/特写/近景/中景/全景/远景） | "镜头"不是景别 |
| 跟移 / 移动镜头 / 跟拍（混用） | 统一为 **跟拍** | 与「移镜」区分：跟拍是镜头跟着主体走 |
| 特写（当大特写用） | 信息/情绪爆点写 **大特写**，人物情绪写 **特写** | 两者能混用就等于没有景别设计 |

### visual（首帧画面）六要素（缺一即不合格）

> **景别 + 机位/角度 + 主体位置与朝向 + 前景/背景层次 + 光线方向与质感 + 关键道具位置**（+ 风格）

| 要素 | 必须写到 | 判定口径 |
|---|---|---|
| 景别 | 大特写 / 特写 / 近景 / 中景 / 中近景 / 全景 / 远景 / 大远景 | **必须写具体景别**；只写"镜头""画面"＝不合格 |
| 机位/角度 | 平视 / 俯拍 / 仰拍 / 过肩 / 越轴侧 / 贴地视角 | 说清摄影机在哪、朝哪 |
| 主体位置与朝向 | 画面左/中/右三分区 + 脸部或身体朝向 | 写"画面右侧三分之一、3/4 侧脸朝左"这类可执行坐标 |
| 前景/背景层次 | 前景挡什么 + 背景是什么 | 至少一层前景（肩膀/栏杆/雨丝）或明确的背景信息，禁止主体贴死空背景 |
| 光线方向与质感 | 光源方向 + 硬/软 + 冷暖 | "暖黄门灯从右后方打来、硬光"；"阴天无方向冷光" |
| 关键道具位置 | 道具在谁手里、画面哪个位置 | "信封在画面中心偏下、被指节压出折痕" |

- **长度与要素的取舍**：常规镜约 60 字，关键镜（大特写/冲撞点）可到 90 字；**要素写不下就拆成两镜，
  绝不删要素凑字数**。六要素是清单，不是句式——按"景别→主体→层次→光线→道具"顺序写最省字。
- ✅ 正例：`大特写，俯拍，手指压在信封封口上，画面中心偏下；前景袖口边缘，背景虚化的雨夜门灯；暖黄硬光从右后方勾出手指轮廓；火漆印正在指纹下方。`
- ❌ 反例：`镜头对着他，气氛很紧张。`——没有景别、没有机位、没有可拍的东西。
- 示例（叙事镜）：`中近景，平视，陈拾右手举着信封站在雨里，画面右侧三分之一、身体朝左；前景是虚化的雨帘，背景老旧邮局门口；暖黄门灯从右后方打亮信封；主体穿着旧邮差制服。`

### motion（动作/运镜）公式：起点 → 运动方式 → 终点

> **起点 → 运动方式 → 终点**（+ 速度/节奏）

示例：`起点：他站在雨里举着信封 → 缓慢把信封贴上胸口、低头 → 停在信封贴住心口、雨声变大`

- **禁止只用"平移 / 推近 / 拉远"这类空模板**：它们没写清"从哪到哪、镜头为什么动、什么时候停"，
  三镜连写"缓慢推近"全片就只剩一种运动。
- **每镜至少一种非平移运动**（按情绪选，一镜只用一种）：
  **跟拍**（跟着人物走）、**甩镜**（快速摇到新主体，带运动模糊）、**手持晃动**（不安/纪实感）、
  **升降**（机位高度变化，俯仰关系跟着变）、**环绕**（绕主体走弧线）、**变焦**（焦距变化，机位不动）、
  **镜头内主体运动带动**（人物逼近镜头/撞向镜头/从画外闯入）。
- **同一场连续三镜不得使用同一种运动方式**：写成 跟拍 → 手持逼近 → 环绕 这样交替；
  连续三镜同一运动 = 调度单调，退回改 `motion`。
- **至少一种非平移运动**与「相邻镜禁止反向运镜」（见第四节 `cam` 字段）不冲突：
  反向是方向问题，类型多样是选择问题——同向的甩镜/跟拍不算反向。
- ✅ 正例：`起点：他坐在桌前 → 手持跟拍他起身冲出门、轻微晃动并加速 → 停在门框挡住画面的半秒。`
- ❌ 反例：`镜头缓慢推近。`（全片每镜都这样写 = 单调平移，观众看不出情绪变化）
- **一镜一个连续动作段落**；不要在一个镜头里写多个动作串联，也不要写跨镜切换（切镜由分镜表组织）。
- **首帧与运动不重复**：visual 描述静止状态，motion 描述之后发生的变化。
- **`motion` 由两部分组成**：**主体动作节拍**（`timeBeats` 三拍，见下节）+ **运镜**（起点 → 方式 → 终点，
  见 `camera` 十二式）——只写运镜就是"只会平移"的根源。

### timeBeats（每镜三个时间节拍，强制动作有层次）

**硬规则：每镜必须把主体动作拆成 3 个时间节拍——`[0s] 起势 → [中段] 发力 → [结尾] 落点`。**

两条写法都合法，**优先用结构化字段**（画布会把字段单独注入视频提示词，段落更清晰）：

1. **结构化（首选）**：分镜 JSON 里给独立的 `timeBeats` 数组，每拍一条：
   `"timeBeats":["0s 背对镜头、肩线绷住","1.2s 肩先转、眼后转、右手撑住桌面","2.4s 停在 3/4 侧脸、指节压白"]`
2. **写进 `motion`（兼容旧格式）**：`[0s] … → [中段] … → [结尾] …；<运镜，起点 → 终点>`

模型只演写出来的节拍；只写"缓缓转头"= 一个节拍 = 模型只会做最省力的平移。

| 镜头类型 | [0s] 起势 | [中段] 发力 | [结尾] 落点 |
|---|---|---|---|
| 对话镜 | 低头看信、嘴半张 | 抬眼看向对方、把信按在桌上 | 指尖顶住桌面、话说完、视线不移 |
| 冲撞镜 | 站在门口、肩线绷紧 | 一步跨进来、手掌推向桌面（椅子被撞开） | 手停在桌面、对方后退半步、纸散开 |
| 情绪镜 | 背对镜头、肩膀起伏 | 肩先转、眼睛后转、右手撑住桌面 | 停在 3/4 侧脸、眼泪停在睫毛上、不眨眼 |

- **该做**：三段都写**可见动作**（身体部位 + 方向 + 落点），三段之间姿势/位置**必须真的变化**，每段都能被拍到一帧。
- **不该做**：三段写同一个动作的不同情绪（"他犹豫 → 更犹豫 → 非常犹豫"）= 0 个节拍；也不要写心理（"他下定决心"）。
- **动作量下限**：`duration ≥ 2s` 的镜头，timeBeats **不得少于 3 条**；`≤1s` 的快切镜允许 1 条（多写演不完）。
- ✅ 正例：`"timeBeats":["0s 背对镜头、肩线绷住","1.2s 肩先转、眼后转、右手撑住桌面","2.4s 停在 3/4 侧脸、指节压白"]` + `motion: "手持微晃左移跟拍，起于他右后方、止于他正面偏左"`
- ❌ 反例：`他缓缓转头`——一个节拍，模型只会给一个平移/微动。
- **判定**：能数出 3 个带时间锚点（`[0s]` / `[中段]` / `[结尾]`，或"起初/随即/最后"）的可见动作阶段，
  且结尾状态与 `tail` 写的接点一致。

### camera（机位 / 镜头 / 运动三件套，禁止只写"推拉摇移"）

三件套分工：**机位与镜头写进 `visual`，运动写进 `motion`**。只写"推近"等于没说清用什么镜头、从哪推到哪。

**① 景别 × 焦段**（`visual` 里写"近景，85mm"）

| 景别 | 常用焦段 | 典型用法 | 情绪效果 |
|---|---|---|---|
| 大远景 / 远景 | 超广角 14–24mm | 环境交代、人物渺小 | 孤独、压迫、史诗感 |
| 全景 | 广角 24–35mm | 关系建立、动作调度 | 客观、疏离、空间清楚 |
| 中景 | 标准 50mm | 对话、信息交换 | 自然、旁观、贴近人眼 |
| 中近景 / 近景 | 中长焦 85mm | 情绪、反应镜头 | 亲近、聚焦、背景柔化 |
| 特写 / 大特写 | 长焦 135–200mm | 细节揭示、情绪爆点 | 压缩、紧张、窒息 |

**② 光圈 × 景深**（`visual` 里写"f/2.8 浅景深"）

| 光圈 | 景深观感 | 适用 |
|---|---|---|
| f/1.4 | 极浅，背景糊成色块 | 梦幻人像、夜戏孤光、情绪特写 |
| f/2.8 | 浅，主体与背景分离 | 叙事主力、对话镜 |
| f/4 | 中等，人与背景都可辨 | 群像、双人对峙 |
| f/8 | 深，环境全清晰 | 建立镜头、动作全景、纪实 |

判定：**情绪镜 / 冲撞镜必须写焦段与光圈**（大特写 135–200mm + f/1.4–2.8；远景 14–24mm + f/8）；
其余镜头可省略。全场统一 f/1.4 = 背景全糊、看不出在哪，不合格。

**③ 运镜十二式**（写进 `motion` 的"运动方式"段，必须带起点 → 终点）

| 运镜 | 一句触发条件 |
|---|---|
| 推近 | 要压向情绪或让人看清细节时（从中景推到近景，不是一直推） |
| 后拉 | 要揭示处境、让观众从人物身上抽离时 |
| 左摇 | 要顺着视线往左带出新信息时 |
| 右摇 | 要带出主体右侧的人或空间关系时 |
| 仰摇 | 要从低往高拍、制造压迫或崇高感时 |
| 俯摇 | 要从高往低拍、揭示布局或让主体显弱时 |
| 左移跟拍 | 人物横向走位大（超过画面 1/4）时，镜头同速横跟 |
| 前移穿入 | 要穿过前景进入场景、形成沉浸感时 |
| 升起俯视 | 要收尾揭示环境规模、或人物被环境吞没时 |
| 左环绕 | 对峙/宣言要转出轮廓与空间层次时 |
| 甩镜 | 冲撞/转场要硬切到新主体时（带运动模糊，切完必须稳住） |
| 焦点转移 | 注意力要从人转到道具、或从道具转回人时（机位不动，只变焦平面） |

其余可用：右移跟拍 / 右环绕 / 下降贴近 / 后退撤离 / 变焦推进 / 定镜凝视——同法写"起点→终点"，不要只写名字。

- **归并大类（「连续三镜不同运动」自检时按大类比）**：推（推近 / 前移穿入）、拉（后拉）、
  摇（左摇 / 右摇 / 仰摇 / 俯摇）、跟（左移 / 右移跟拍）、升降（升起 / 下降）、环绕、甩、变焦（变焦推进 / 焦点转移）、手持。

**④ 单镜容量上限（超了就拆镜，这是稳定性的来源）**

| 项目 | 上限 | 怎么判（可机械核对） |
|---|---|---|
| 主运镜 | **1 个** | `motion` 里能数出两个不同运动动词（推+摇 / 移+环绕）= 超限 |
| 主动作链 | **1 条**（起势→发力→落点） | 出现两个互不相干的目标动作（"转身" + "端起杯子"）= 超限 |
| 主要角色 | **2 名** | `characters` 数组 > 2，且都要在画面里演戏 = 超限 |
| timeBeats | **3 条** | `duration ≥ 2s` 的镜头不足 3 条 = 不合格（见上节） |

超限一律**拆镜**（换景别 / 换机位接），不要在一镜里堆——堆了模型只执行前半段，下一镜必然对不上。

### vfx（特效与物理细节，不写就没有）

视频模型**不会自己加特效**：不写就是空白。`vfx` 没有独立字段——粒子/光效/物理/环境写进 `visual`，
镜头类（晃动 / 呼吸 / 拖影）写进 `motion`。

| 类别 | 写法示例 | 适用 |
|---|---|---|
| 粒子 | 雨丝斜打（细密、有方向）、尘粒在光柱里浮动、雪片近大远小、火星随呼吸明灭 | 氛围 / 苦情 / 古装 |
| 光效 | 逆光镜头光斑、路灯钠黄溢光、闪电瞬时照亮半张脸、手电光柱切过烟雾 | 夜戏 / 悬疑 |
| 物理 | 衣角被风掀起、水面涟漪一圈圈扩散、纸张翻飞、湿发贴在颊边 | 写实 / 生活 |
| 镜头 | 轻微手持晃动、镜头呼吸感（缓慢起伏）、运动模糊拖影 | 纪实 / 动作 |
| 环境 | 烟雾贴地弥漫、蒸汽升腾、水汽在玻璃上凝结 | 冷峻 / 工业 |

- **硬规则：每场至少 3 镜写 vfx**；纯对话文戏可降到 1 镜，**但不得为 0**。
- **判定**：每镜 `visual`（或 `motion`）里能找到一个**具名物理/光效细节**（名词 + 方向或强度），
  例如"雨丝从右后斜打""钠黄溢光反在指纹上"；数得出"每场 ≥3 镜"即合格。
- vfx 必须**带方向或强度**；不写方向的粒子在成片里就是噪点。
- ✅ 正例：`…；前景雨丝从右后斜打过画面，路灯钠黄溢光在指纹上反出一道亮边。`
- ❌ 反例：`画面很唯美`——空话，模型不知道画什么。

### negative（负向要求清单：在分镜阶段规避，不是生成后再后悔）

画布自动组装的视频提示词**没有负向槽位**——所以 negative 的主用法是**写分镜时逐条转成"正向确定写法"**；
只有在手写提示词覆盖（含 `subject_definitions` 的完整结构）或厂商原生支持负向参数时，
才把清单作为"负向：…"追加到末尾。

**通用必备（每场逐条检）**

| 负向项 | 正向规避写法（写进 `visual` / `motion`） | 怎么判 |
|---|---|---|
| 换脸 | 写死"与 @角色@ 一致，脸型/眼型不变" | 能搜到"一致/不变" |
| 五官漂移 | 逐镜复述不变的眉形、鼻梁、下颌线 | 相邻镜外观词逐字相同 |
| 服装变化 | 逐镜复述服装关键件（"旧邮差制服、左胸口袋"） | 服装词全场同一套 |
| 手部畸形 | 写清手部姿态与遮挡（"右手五指并拢按在桌面"） | 有动作的镜都写了手 |
| 多指 | 明确手指数与动作（"双手十指交握"） | 手部特写必写 |
| 穿模 | 写清前后遮挡关系（"手在桌面之上、不入桌面"） | 有接触动作就写 |
| 闪烁 | 固定光源方向与强度（"门灯始终从右后方打来"） | 光线描述跨镜一致 |
| 风格突变 | 每镜沿用同一句风格词 | 风格词全片统一 |
| 动作僵硬 | timeBeats 三段姿势真有变化 | `duration ≥ 2s` 的镜头 ≥3 拍 |
| 人物凭空出现/消失 | 首镜写站位、末镜用 `tail` 写清位置与退场方向 | 每镜有位置关系 |
| 口型与台词不同步 | 有台词必写"开口说话、口型清晰可见"（近景/中近景、脸可见） | 有 `dialogue` 的镜必查 |

**按题材追加（勾选后同样要找到对应规避写法）**

| 题材 | 追加负向项 |
|---|---|
| 古装 | 现代物件（手表 / 拉链 / 塑料 / 电线 / 汽车） |
| 室内 | 窗外光线突变（白天拍成夜晚、阴晴乱跳） |
| 多人 | 身份互换（服装、配饰串到别人身上） |

- **判定**：每场通用 11 项逐条能在分镜里找到规避写法；题材项按标签勾选，勾了就必须有对应写法。

### 冲撞感：怎么用镜头写出"撞"（每场至少一个冲撞点）

**每场至少一个冲撞点**：人物之间（对峙、逼问、撕扯、抢夺），或人物与环境/物件之间
（撞门、摔碎、被雨砸、被车灯扫过、被推上墙）。写不出冲撞点的场 = 这场没戏，回去加冲突，
**不要靠运镜硬撑**。

四种手段，同一个冲撞点至少叠两种：

| 手段 | 怎么写进分镜 | 判定标准 |
|---|---|---|
| 短镜头堆叠 | 冲撞点前后连用 1–1.5s 短镜（爆发瞬间可到 0.3–0.8s），每镜只留一个动作 | 冲撞段落里出现 ≥2 个 ≤1.5s 的镜头 |
| 反向构图 | 不越轴的前提下让相邻两镜构图重心相反（正反打、俯仰互换、主体左右占位互换） | 相邻两镜构图重心方向相反，且轴线关系仍成立 |
| 突然的机位跳切 | 用 `seg: closeup` 插一个大特写或俯拍，刻意打断轴线一瞬——**切完立刻切回原轴线** | 冲撞点处出现一次景别或角度的突变 |
| 声音突入 | `sfx` 写一个**盖过环境声的短促声音**：撞门、玻璃碎裂、掌掴、急刹、椅腿刮地、呼吸骤停 | 冲撞点那镜的 `sfx` 是"突入型"声音，不是环境底噪 |

- **visual 写"接触瞬间"**：不写"两人起冲突"，写"他的肩撞上她的肩，她的包被撞飞，画面右倾、前景手臂横挡"。
- **motion 写"速度突变"**：`起点：静止对峙 → 突然加速逼近（手持晃动）→ 在相距半臂处急停`。
- **sfx 写"声音证据"**：`椅腿刮地、闷响、急促呼吸`；非冲撞镜只给环境声（雨声/空调声/远处车流）。
- ✅ 正例：冲撞点 = 0.6s 大特写（攥紧的拳头）+ 1.2s 反向过肩（她被推上墙）+ `sfx: 后脑撞墙的闷响`。
- ❌ 反例：全场 motion 都是"缓慢推近"、sfx 全是"雨声"——观众感受不到任何冲击。

### 连续性（最容易被忽略，必须检查）
- **180° 轴线**：对话双方在相邻镜头保持同一侧。
- **服装 / 发型 / 光线 / 天气**在相邻镜头一致；换场要交代时间流逝。
- **相邻镜头的方向与姿态要衔接**（180° 轴线、出入画方向一致）；多镜头一次性生成时
  把衔接关系写进相邻镜头的提示词，模型会在同一条视频里保持连贯。

### 分镜自检（生成分镜后逐条判定，任一不过 → 重拆/重写，不带病生成视频）

| # | 检查项 | 判定标准（可机械核对） | 不过怎么办 |
|---|---|---|---|
| 1 | 每场有冲突点？ | 每场能指出"谁 vs 谁/物"的具体冲撞点，且该处叠了 ≥2 种冲击手段（短镜/反向构图/跳切/声音突入） | 回剧本加冲突，不是靠运镜补救 |
| 2 | 每场有 1 个大特写？ | 每场 `shots` 里至少一镜 `visual` 以「大特写」开头且写明拍的是哪个局部 | 在关键信息/情绪爆点处补一镜（0.8–2s） |
| 3 | 有三镜同运动？ | 任意连续 3 镜的 `motion` 运动类型（跟/甩/手持/升降/环绕/变焦/主体带动）不全相同 | 改中间那镜的运动类型，或拆镜 |
| 4 | 景别是否具体？ | 每镜 `visual` 首句含具体景别；全文搜不到"镜头对着""画面里"这类无景别开头 | 逐镜补景别，缺机位/光线的按六要素补齐 |
| 5 | 场间有因果钩子？ | 每场结尾句是动作/物件（不是总结），且下一场第 1 镜由它引发 | 重写该场结尾，或调整下一场开场 |
| 6 | 六要素齐全？ | 每镜 `visual` 六要素逐项能找到（景别/机位角度/主体位置朝向/前景背景/光线方向质感/道具位置） | 缺项补写；字数超了就拆镜 |

> 前 5 条来自用户实测反馈（剧本不连贯、镜头太粗、运镜单调、缺冲击），是**硬闸门**；
> 第 6 条是质量线。自检结果不需要输出给用户，但**不合格就不许触发视频生成**（视频花钱，分镜重生成不花钱）。


## 三、图片提示词规范

公式：**主体 + 景别/构图 + 环境 + 光线 + 风格质感 (+ 画幅)**

- **角色一致性**（关键）：同一角色跨镜头，描述**逐字复用**设定集里的外观关键词
  （年龄、发型、服装、配饰），只在景别与动作上变化。
- **参考图绑定**：把角色/场景/道具资产连到图片节点的 ref 端口，顺序即 `[图N]`，
  提示词里用 `[图1] 角色：陈拾（旧邮差制服，帆布邮包）` 这样的绑定说明。
- **图片/视频是合并节点（有图就是资产，空节点点开面板生成）**：画布不再区分「生成节点」与
  「资产节点」——同一个 `image` / `video` 节点，有结果（`assetId`）就是资产，没有结果时点开节点
  的生成面板填写提示词后生成；参考图仍靠连线（资产 → ref）与 `@实体@` 引用挂载。
- **要避免**：一个画面里多个主体动作、文字/水印、风格混搭（写实 + 卡通）、
  极端广角导致人物变形。
- 风格统一：整部片用**同一套风格词**（如"写实电影感，暖色调，浅景深"）。

## 四、视频提示词规范

### 多镜头视频：系统自动用「参考生成」结构化格式（不要手写机械拼装）

分镜表驱动的视频节点（`video` 节点连了分镜表）**由画布自动组装结构化提示词**，格式对齐 MiniMax H3 /
优云智算优化后的协议——**机械拼装（风格 + [图N] 绑定 + 镜头列表 + 设定集全文）会让模型把台词、
场景、人物判错**（实测：台词被当画外音、场景串镜）。自动生成的六段结构：

```text
subject_definitions:   <Subject N> 是 <Picture M>… 中的 实体名：外观要点        ← 素材↔主体绑定
summary:               [参考生成] 共 N 镜、总时长 X 秒：从…开始，到…结束；主体：…
retention_analysis:    <Subject N>（出现于 [Shot a]、[Shot b]）：fully_preserved —— 保持…
detailed_description:  风格：…（设定集风格）
                       [Shot 1] 00:00.000 起（镜头标题）：画面；运镜/动作：…；台词：<Subject 2>（S1）
                       用5–6 岁男孩奶音，尾音上扬说：<d>[Chinese] 为什么呀？</d>；音效：…
overall_soundscape:    各镜音效合并
non_diegetic_music:    仅当显式给出（节点扩展参数 {"music":"…"}）时输出，绝不臆造
```

要点（这也解释了它为什么能音画同步）：

- **<Picture N> ↔ <Subject N> ↔ 实体名** 三级绑定：参考图不再只是"[图N] 角色：某某"，
  而是模型能引用的主体；镜头正文里的实体名会被替换成 `<Subject N>`（长名优先匹配）。
- **台词绑定到主体**：`<Subject N>（S1）用<音色>说：<d>[Chinese] 台词</d>`——说话人编号全局唯一，
  首次出现带音色描述，因此口型/音色/台词三者不会错配。
- **绝对时间轴**：每镜标注 `00:MM:SS.mmm 起`，模型据此切镜与对齐口型。
- **前置条件（必须满足，否则格式退化）**：
  1. 分镜表每镜有 `dialogue`（角色名 + 台词逐字）——台词只能来自这里；
  2. 设定集条目描述里带「**外观：**…」与「**声音：**…」两个字段（前者进主体定义，后者进台词音色）；
  3. 参考图已连到视频节点（无参考图时自动回退普通提示词）。
- **手写覆盖**：节点提示词里若含 `subject_definitions`，画布原样发送，不做二次加工（高级用法）。

### 字段落点：写了没用，是因为没落到对的字段上

分镜镜头落库时保留这些键：`title` / `visual` / `motion` / `timeBeats` / `camera` / `vfx` / `negative` /
`tail` / `cam` / `start` / `seg` / `characters` / `scene` / `props` / `duration` / `dialogue` / `sfx`。
**结构化字段（`timeBeats` / `camera` / `vfx` / `negative`）会被画布单独提取**，逐镜拼进视频提示词的
「动作节拍 / 机位·焦段·运镜 / 物理特效」三段；没写就是空，模型不会自己补。落点对照：

| 内容块 | 落在哪个字段 | 组装后变成 |
|---|---|---|
| timeBeats（3 拍：起势→发力→落点） | `timeBeats` 数组（首选）或 `motion` 前半段 | `动作节拍（按时间推进，不可省略任何一拍）：… → … → …` |
| camera 三件套 | `camera`（首选），或拆进 `visual`（景别+焦段+光圈）+ `motion`（运镜） | `机位/焦段/运镜：…` |
| vfx | `vfx`（首选），或写进 `visual` / `motion` | `物理特效（必须可见）：…` |
| negative | `negative`（逗号分隔短语） | 合并进逐镜末尾的「禁止：…」清单 |
| 台词与音色 | `dialogue` + 设定集「声音：…」 | `台词：<Subject N>（S1）用…说：<d>…</d>` |
| 音效 / 环境声 | `sfx` | `音效：…`（并合并进 `overall_soundscape`） |

> 结论：**只写 `visual` 不写 `motion` = 没有运动；`timeBeats` 不写 3 拍 = 只有平移；`vfx` 不写 = 没有特效。**
>
> 补充一条**切段**口径：铺开时画布会按真实镜头边界把这张分镜表切成若干段生成（默认单段上限 15s，
> 面板上可调；MiniMax 这类弱衔接模型建议 6–10s）。切点只落在 `scene_change` / `closeup` /
> `new_character` 三种镜头上，所以**同一个人同一段连续动作不要拆成多个 continuation 镜**——
> 宁可给这一镜更长的 `duration`；真要换机位，就让下一镜成为三种切点之一（哪怕插一镜大特写）。

### 分镜衔接：分段生成能不能接上，全看这四件事

短剧一集必然切成多段生成（模型单次有时长上限），而**每段是独立采样的——模型看不到上一段最后发生了什么**。
所以"接不上"不是模型笨，是分镜里没写接点。分镜表镜头除 visual/motion 外还有四个衔接字段
（画布「分镜衔接」开关打开时，AI 自动写；也可手写）：

| 字段 | 写什么 | 硬规则 |
|---|---|---|
| `tail` 接点尾态 | 本镜**最后一刻**的状态：姿势停在哪个动作的中途、朝向、视线落点、手持物、位置关系 | **必须是"动作进行中"**，绝不允许写"已完成/站定/看向"——切在静止定格，下一镜没东西可接 |
| `cam` 运镜延续 | 本镜的运镜方向 + 速度，写成下一镜能接着走的形式（"右移横移，匀速，未停"） | 相邻镜**禁止反向运镜**；要反向就改遮挡/过肩/特写插入 |
| `start` 起始态 | 仅第 1 镜或非续帧镜头需要 | 续帧镜头不写（自动承接上一镜 tail） |
| `seg` 段落类型 | `continuation` 续帧（默认）/ `scene_change` 换场 / `new_character` 新角色入场 / `closeup` 特写插入 / `opening` 首段 | 决定生成时走哪条链路（见下） |

**方向要分清（这是最容易写错的地方）**：每镜的 `tail` / `cam` 描述的是**本镜自己的结尾**，
它们是留给**下一镜**的「接点」；而每一镜开头「承接上镜结尾」引用的，是**上一镜**的 `tail`。
两个方向别混：写本镜时想"我演到哪、怎么交给下一镜"，而不是"我该从哪开始"。
旧分镜若没写 `tail`，系统会退到上一镜的 `motion` 并**明确标注"按最后动作推断"**——这是兜底，不是等价物；
要真的接得上，`tail` 必须手写或由 AI 写出。

配套的拆分纪律：

- **一镜只做一个主动作**：转身+走路+推镜塞进一镜，模型只执行前半段，下一镜必然对不上。
- **一段一运镜**：又推又横移又摇 = 下段没法延续。
- **大位移拆镜**：人物横移超过画面 1/4、或走位大改，再拆一镜（换景别接）。
- **轴线一致**：两人对话，男左女右在相邻镜必须保持，不得越轴。
- **时长按节拍切 4–6 秒**，别按模型单次最大时长怼满——段越长，中间漂移概率越高、首尾帧差越大越容易崩。

生成端的自动调度（画布已实现，无需手写提示词）：

1. **续帧段（`seg: continuation`）** → 自动取上一段的**尾帧**作为本段首帧（不是"最后一帧"，而是在片尾多帧里选"动作进行中、清晰、不抖"的一帧）。**只有这一段类型会接力尾帧。**
2. **首帧与参考图互斥时**（多数厂商如此）→ 尾帧降级为第 1 张参考图 + 提示词软锚定（"第 1 帧必须与 [图1] 一致"），
   节点上会显示「接缝通过 / 接缝偏跳」，偏跳就打回重生成或改「硬首帧」模式（硬首帧放弃参考图，画面绝对承接）。
3. **换场段（`seg: scene_change`）** → 不接尾帧，直接按场景参考建立空间。
4. **新角色入场段（`seg: new_character`）** → 不接上段尾帧（首尾帧图里没有他就锁不住他），走参考图模式，要求从画面内自然进入。
5. **特写/细节插入段（`seg: closeup`）** → 允许跳切，不要求画面连续（接缝阈值放宽到 0.15）。
6. 生成后**自动接缝校验**：本段首帧 vs 上段尾帧的相似度，同场续帧 0.55、跨场换景/新角色 0.35、特写插入 0.15，
   不达标在节点上告警（不静默），并建议调低运动幅度重生成。

> 一句话：**角色一致性靠参考图，剧情衔接靠尾帧接力 + 接点尾态；剪辑端只是兜底，救不回没写接点的分镜。**

### 导演简报六组件（顺序即权重：构图在前，质感在后）
**场景（环境+光线）→ 主体（身份+细节）→ 动作（一次一个节拍）→ 运镜（机位+镜头+速度）→ 音频（音乐+音效+环境）→ 节奏/风格（时长+情绪+调色）**

- **音频指令绝不能省**：视频模型原生生成声音，不写音频指令就会得到随机的环境声——
  哪怕一句话也要写（音乐情绪、关键音效、环境底噪）。
- **单拍规则**：一个时间段 = 一个动作节拍；4–7 秒一个节拍，10–15 秒最多 3–4 个节拍；
  一段里塞两个叙事转折会劣化动作与物理一致性。
- **时长与内容量匹配**：3 秒只够一个动作，别写"转身、拔枪、开枪"三连；4 秒塞不下三个场景变化。

### 公式：**主体动作 + 运镜方式 + 环境变化 + 节奏/时长**

- 单动作、单运镜；**不要写场景切换**（切换交给镜头之间的衔接）。
- 与上一镜衔接：从上一镜的**末帧**继续动作（画布支持 last 帧作为视频节点输入）。
- 对白/音效单独交给配音（TTS）节点，不要写进视频提示词。

### 避坑清单（提示词）
1. **引用模糊**：说"参考 @图1"没用——要说参考什么（形象？运镜？动作？节奏？音色？）。
2. **指令冲突**：同一段里别同时要"固定镜头"和"环绕镜头"。
3. **内容过载**：4–5 秒塞多个场景变化 = 物理不可行，动作会糊。
4. **关键词汤**：不要"8k、masterpiece、trending"——用技术性描述（浅景深、35mm、体积光）。
5. **不连贯动作**：别写"他跑起来然后停下"——写成有过渡的流畅动作语言。
6. **忽视音频**：音效设计大幅提升成片质量。

## 五、设定集（Series Bible）维护

- **风格**：一句话定调（题材 + 年代 + 色调 + 质感）。
- **角色 / 场景 / 道具卡**：`名称 + 一句话设定 + 外观关键词`。
- 首次出现某元素时补卡；此后**引用而非重写**，保证跨集跨镜一致。
- 名字要唯一且可检索（不要"路人甲1""路人甲2"混用）。

## 六、交付前自检清单

- [ ] 剧本：开场 10 秒有钩子；结尾有悬念；对白口语化；**每场目标/阻碍/转折/代价四要素各至少一处**；
      **每场结尾是动作或物件的因果钩子（不是总结句），且下一场由它引发**
- [ ] 一致性：人名/地名/道具与设定集逐字一致；角色外观描述未漂移
- [ ] 分镜：镜头数 × 时长 ≈ 目标时长；每镜一个动作；相邻镜头轴线与光线连续；
      **每镜 `visual` 六要素齐全且景别具体**；**每场至少 1 个大特写**
- [ ] **冲撞**：每场至少一个冲撞点，且叠了 ≥2 种冲击手段（短镜头堆叠 / 反向构图 / 机位跳切 / 声音突入）
- [ ] **调度**：`motion` 写成"起点→运动方式→终点"，含非平移运动；**同一场连续三镜不含同一种运动方式**
- [ ] **timeBeats**：每镜有 3 拍（`[0s]` 起势 → `[中段]` 发力 → `[结尾]` 落点），写进 `timeBeats` 数组或 `motion`；
      `duration ≥ 2s` 的镜头**一律不少于 3 条**，`≤1s` 的快切镜允许 1 条
- [ ] **camera 容量**：每镜只有 **1 个主运镜 + 1 条主动作链**（多一个就拆镜），运镜写全「起点 → 方式 → 终点」
- [ ] **vfx / negative**：每场 **≥3 镜**写了具名特效或物理细节（纯对话文戏可 1 镜、不得为 0）；
      negative 通用项 + 题材项写进 `negative` 字段（或转成正向规避写法）
- [ ] **切段友好**：同一角色的同一段连续动作没有被拆成多个 continuation 镜；
      换机位时下一镜是 `scene_change` / `closeup` / `new_character` 之一（切点干净，剪辑时是硬切不是硬接）
- [ ] **节奏**：同一场里至少一次明显的时长对比（快切/长镜）；景别随情绪推进而不是随机
- [ ] 提示词：图片含景别/光线/构图；视频单动作单运镜；风格词全片统一；**每条视频提示词都有音频指令**
- [ ] 资产：命名含项目 + 集数 + 场次（便于检索与后期对轨）
- [ ] 成片：字幕覆盖全部对白；配音与画面同长；转场时长 ≤ 1 秒
