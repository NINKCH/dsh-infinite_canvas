# 创作方法论（剧本 / 分镜 / 提示词）

本技能是**创作手法**规范；画布的操作流程（建项目、写节点、触发生成）见 `canvas-studio`。
两者配合使用：先按本技能写出合格内容，再按操作规范落到画布上。

## 一、短剧剧本方法论

### 结构与节奏
- **单集时长**：竖屏短剧常见 60–120 秒；对应 **4–8 场**，每场 15–30 秒。
- **开场 10 秒必须有钩子**：悬念、冲突、反常画面或一句扎心的台词；不要铺垫世界观。
- **三段压缩**：建置（1–2 场）→ 对抗（主体，冲突升级）→ 解决/反转（1 场，留悬念）。
- **每场一个小目标**：人物想要什么 → 遇到什么阻碍 → 结果如何转折。写不出这条，这场就该删。
- **结尾留钩子**：最后 3–5 秒抛出新信息或未解之谜（下集驱动力）。

### 分场格式（固定八要素）
```
【第 N 场】内/外景 · 地点 · 时间
人物：A、B
画面：可拍摄的动作与环境（不写心理活动）
对白：
A：口语化短句。
B：……
```
- **只写能拍出来的东西**：摄影机拍不到的心理描写一律改成动作、表情或对白。
- **对白**：短句、口语；单场不超过 6 个来回；避免解释性台词（"你知道的，当年……"）。
- **一致性**：人名、地名、道具名与设定集**逐字一致**，禁止擅自改名或新增设定。
- **输出格式**：直接给可用剧本正文，不要解释、不要提纲、不要"待生成"占位。


## 二·五、资产设定图版式（角色/道具/场景的专业排版，拒绝简单三视图）

简单三视图信息量不足——设定图要做成**专业设定集排版**：主图 + 特写 + 表情/色卡分区呈现，
一图读懂资产的全部视觉设定。**版面里绝不渲染成段文字**：文字渲染型模型画长文本必然乱码（实测），
面板文字只允许 ≤4 字短标签（面板名 / 表情名 / 颜色名）。同一资产在所有分格中外观**完全一致**——
**已连接参考图时，参考图形象是唯一事实**，逐格严格复制；未连接参考图时逐格复用设定集外观关键词。

### 角色设定图（16:9 横版——按「六段式」结构写提示词，实测出图最稳）

提示词按以下六段组织，**方括号段名照写**（模型对显式分段结构的遵循度显著更好）：

- **【总起】**一句话交代：16:9 横版专业设定集排版、深色简洁背景、风格基调（如 写实电影感）、
  同一角色在所有分格中外观完全一致。
- **【身份锚】**声明参考图是同一角色的真实照片：严格保持脸型 / 眼型 / 耳形 / 毛量 / 口鼻比例 / 体型，
  只改变姿势与视角；**忽略照片里的临时配饰**（狗绳、挂牌等），配饰一律按提示词文字描述绘制。
  绑定几张参考图就写几个 [图N]。
- **【主体】**中央大幅全身立绘（正面站姿）：体型写量化并加反例（如「约 3 公斤、肩高 20 厘米；
  不是中型犬，不是萨摩耶/银狐/柴犬」——易混淆品种必须显式排除）、毛色毛发、五官、四肢尾巴，
  以及固定配饰的完整描述。**并声明姿态是自然空手站立**：四肢自然着地 / 下垂，口部闭合或自然吐舌，
  **不抱、不拿、不叼、不踩、不坐任何外物**。
- **【主图下方·三视图（必须项）】**正面／侧面／背面三格全身站姿——同一角色只换角度，
  交代侧背形态（后续视频一致性靠它）。
- **【右侧窄栏·自上而下分块；每块内容全图只出现一次】**
  ① 脸部特写一格 + 一行 ≤12 字的五官短标注；
  ② 配饰格（有固定配饰时）：正 / 背两张小图并排，可刻短字，并注明「该物在本图内只出现这一处」；
  ③ 表情格：6 个头部小头像分两行（每行 3 个），每个下方只标两字表情名。
- **【文字规则】**图内文字极少：只保留两三个字的短标签，黑色细体、笔画清楚、字要写大；
  不写任何大标题、说明段或长句。
- **【画面白名单】**反幻觉白名单，逐类点名，实测能压住乱入元素：
  「画面中**只有这一只角色本体与它的固定配饰**（如 项圈 / 挂牌），以及上述分格内容；
  **没有任何被抱、被拿、被叼、被踩或被坐着的物品**——纸箱、包裹、篮子、玩具、食物、乐器、器材、
  道具、家具一律不出现；没有人物、没有其他动物、没有场景陈设、没有文字水印。」

要点：**每块内容全图只出现一次**（配饰在配饰格画过，主图描述就不再重复强调它）；
**外物是最常见的乱入**（"抱着纸箱""叼着玩具""踩着道具"），必须在【主体】声明空手姿态、
并在【画面白名单】里逐类点名排除；反例约束同样有效——易混淆的品种 / 风格务必写进【主体】的排除句。

### 道具设定图（横竖皆可——按道具特性选，不限制）
- **画幅选择**：长条形/单件道具（剑、箫、杖）竖版更能展示完整形态；
  组合道具、带场景感或横向结构的道具用横版能并列更多细节与色卡——排版逻辑不变，画幅自由。
- **顶部**：道具名大标题（≤6 字）。
- **中央主图**：道具斜 45° 悬浮展示，带氛围光/粒子效果，占画面主体。
- **细节特写 2–3 格**：材质纹理、关键部件，格内无文字。
- **侧栏侧视图**：同一道具的正侧面完整形态。
- **底部颜色参考**：3–5 个圆形色卡，每个下方标注颜色名（≤3 字，如「赤红 / 熔金 / 绛紫」）。
- **禁止**：铭文 / 短诗 / 说明文字渲染（易成乱码）。

### 场景设定图（主场景图 + 环绕补充小图）
- **主场景图占画面主体**（全景建立镜头，交代空间结构与光线方向）——不要切成几张等大的长条格，
  那样每格都是局部长图，场景信息反而看不全。
- **环绕补充小图（3–6 张，位置与数量不拘）**，参考版式：
  - 右侧一列：**多角度图**（俯瞰、贴地、第一人称视线等其他机位）+ **其他时间图**（夜景 / 雨雾 /
    逆光等不同时间段或天气下的同一场景）；
  - 底部一排：**细节格**（标志物 / 入口 / 材质纹理 / 关键道具在场景中的位置）。
- 每张小图下方一行**短标注（≤6 字**，如「入口·夜」「雨中·逆光」）。
- 上述布局是大致参考、不强制；所有格子的光线方向、天气、色调须与主图统一
  （展示不同时间段时在标注中说明）。
- **禁止**：成段说明文字。

### 画面感要点
- 用一个**具体的可视细节**替代形容词：不写"他很悲伤"，写"他把没送出的信折了三次，塞回口袋"。
- 每场至少一个"能被记住的画面"（记忆点）。

## 二、分镜拆解方法论

### 粒度
- **一段连续的动作节拍 = 一个镜头**；不要把两个不相关的动作塞进一个镜头。
- **单镜头按时长谱系取值**（见下）；各镜时长之和 = 目标视频总时长，**按内容写足、不设硬上限**
  （如 15 秒 ≈ 4–7 镜，30 秒 ≈ 8–14 镜）。整个分镜表会组合成**一条多镜头提示词，由视频模型一次性生成整段视频**
  （镜头间由模型硬切，不需要逐镜生成再拼接）。
- 一场通常拆 4–8 镜：建置镜（环境/全景）→ 主体镜（中近景）→ 情绪镜（特写）→ 动作镜（跟移/推拉）；
  镜越短节奏越快，每镜的提示词要越聚焦。

### 节奏谱系（时长为情绪与节拍服务，**拒绝均匀分布**）
| 镜头类型 | 时长 | 用途 |
|---|---|---|
| 快速冲突 / 打斗 / 追逐 | **0.3–0.8s** | 快切、追逐、冲突爆发 |
| 重要反转 / 冲击 / 卡点 | **1–2s** | 反转、关键瞬间 |
| 普通叙事 / 对话 / 环境交代 | **2–4s** | 日常推进 |
| 长镜头情绪沉淀 | **≥5s** | 情绪酝酿、氛围、一镜到底 |

- **同一场至少制造一次明显的节奏变化**（例：3s 叙事 → 0.6s 快切×2 → 1.5s 反转 → 5s 情绪长镜）——
  时长全部一样就没有节奏感，画面再精致也不行。
- **快切镜头的提示词要极短**（一个动作、一句画内信息）；信息量大的镜头才配长时长——时长与内容量必须匹配。
- duration 支持一位小数（0.6、1.5 都合法）。

### 情绪 → 景别（根据情绪选景别）
| 情绪 | 景别 |
|---|---|
| 孤独 / 绝望 / 宏大危机 | 远景 |
| 对峙 / 动作 / 关系建立 | 全景 |
| 对话 / 试探 / 信息交换 | 中景 |
| 震惊 / 怀疑 / 内心动摇 | 近景 |
| 崩溃 / 嘶吼 / 情绪爆发 | 特写 |
| 关键细节 / 道具揭示 / 伏笔 | 大特写 |

口诀：**冲突用全景，揭秘转近景，爆发给特写，反转可拉远**；
镜头距离的变化本身在讲情绪：拉开距离 → 进入内心 → 强烈冲击 → 重新审视。

### 剧情四阶（场景内部弧线，也是单集结构）
1. **冲突出现**：常态被打破；
2. **信息升级**：真相推翻旧认知；
3. **情绪爆发**：积压矛盾总爆发——这里是全片节奏最快处（快切 + 特写）；
4. **结局反转**：意料之外，伏笔回收（可拉远收束）。

### 术语表
- **景别**：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写（极致特写：只拍眼睛、嘴、道具细节）。
- **运镜**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕；**一镜只用一种运镜**。
- **高级运镜（按需选用）**：希区柯克变焦（推拉+变焦的眩晕感）、低角度仰拍（英雄感）、
  快速摇镜（运动模糊）、FPV 第一人称主观（需要连续运动的环境才成立）、
  航拍俯冲（要有明确落点，否则画面漂浮）、机械臂跟随（多角度贴视线）。

### visual（首帧画面）公式
> 景别 + 主体姿态 + 环境 + 光线 + 构图重心（+ 风格）

示例：`中近景，陈拾右手举着信封站在雨里，老旧邮局门口，暖黄门灯打在信封上，主体位于画面右侧三分之一，写实电影感`

### motion（运动/情绪）公式
> 动作节拍 + 运镜方式 + 节奏

示例：`他缓慢把信封贴上胸口，镜头缓慢推近，节奏由慢到停顿`

- **一镜一个连续动作段落**；不要在一个镜头里写多个动作串联，也不要写跨镜切换（切镜由分镜表组织）。
- **首帧与运动不重复**：visual 描述静止状态，motion 描述之后发生的变化。

### 连续性（最容易被忽略，必须检查）
- **180° 轴线**：对话双方在相邻镜头保持同一侧。
- **服装 / 发型 / 光线 / 天气**在相邻镜头一致；换场要交代时间流逝。
- **相邻镜头的方向与姿态要衔接**（180° 轴线、出入画方向一致）；多镜头一次性生成时
  把衔接关系写进相邻镜头的提示词，模型会在同一条视频里保持连贯。

## 三、图片提示词规范

公式：**主体 + 景别/构图 + 环境 + 光线 + 风格质感 (+ 画幅)**

- **角色一致性**（关键）：同一角色跨镜头，描述**逐字复用**设定集里的外观关键词
  （年龄、发型、服装、配饰），只在景别与动作上变化。
- **参考图绑定**：把角色/场景/道具资产连到图片节点的 ref 端口，顺序即 `[图N]`，
  提示词里用 `[图1] 角色：陈拾（旧邮差制服，帆布邮包）` 这样的绑定说明。
- **要避免**：一个画面里多个主体动作、文字/水印、风格混搭（写实 + 卡通）、
  极端广角导致人物变形。
- 风格统一：整部片用**同一套风格词**（如"写实电影感，暖色调，浅景深"）。

## 四、视频提示词规范

### 多镜头视频：系统自动用「参考生成」结构化格式（不要手写机械拼装）

分镜表驱动的视频生成（视频节点连了分镜表）**由画布自动组装结构化提示词**，格式对齐 MiniMax H3 /
优云智算优化后的协议——**机械拼装（风格 + [图N] 绑定 + 镜头列表 + 设定集全文）会让模型把台词、
场景、人物判错**（实测：台词被当画外音、场景串镜）。自动生成的六段结构：

```text
subject_definitions:   <Subject N> 是 <Picture M>… 中的 实体名：外观要点        ← 素材↔主体绑定
summary:               [参考生成] 共 N 镜、总时长 X 秒：从…开始，到…结束；主体：…
retention_analysis:    <Subject N>（出现于 [Shot a]、[Shot b]）：fully_preserved —— 保持…
detailed_description:  风格：…（设定集风格）
                       [Shot 1] 00:00.000 起（镜头标题）：画面；运镜/动作：…；台词：<Subject 2>（S1）
                       用5–6 岁男孩奶音，尾音上扬说：<d>[Chinese] 为什么呀？</d>；音效：…
overall_soundscape:    各镜音效合并
non_diegetic_music:    仅当显式给出（节点扩展参数 {"music":"…"}）时输出，绝不臆造
```

要点（这也解释了它为什么能音画同步）：

- **<Picture N> ↔ <Subject N> ↔ 实体名** 三级绑定：参考图不再只是"[图N] 角色：某某"，
  而是模型能引用的主体；镜头正文里的实体名会被替换成 `<Subject N>`（长名优先匹配）。
- **台词绑定到主体**：`<Subject N>（S1）用<音色>说：<d>[Chinese] 台词</d>`——说话人编号全局唯一，
  首次出现带音色描述，因此口型/音色/台词三者不会错配。
- **绝对时间轴**：每镜标注 `00:MM:SS.mmm 起`，模型据此切镜与对齐口型。
- **前置条件（必须满足，否则格式退化）**：
  1. 分镜表每镜有 `dialogue`（角色名 + 台词逐字）——台词只能来自这里；
  2. 设定集条目描述里带「**外观：**…」与「**声音：**…」两个字段（前者进主体定义，后者进台词音色）；
  3. 参考图已连到视频节点（无参考图时自动回退普通提示词）。
- **手写覆盖**：节点提示词里若含 `subject_definitions`，画布原样发送，不做二次加工（高级用法）。

### 导演简报六组件（顺序即权重：构图在前，质感在后）
**场景（环境+光线）→ 主体（身份+细节）→ 动作（一次一个节拍）→ 运镜（机位+镜头+速度）→ 音频（音乐+音效+环境）→ 节奏/风格（时长+情绪+调色）**

- **音频指令绝不能省**：视频模型原生生成声音，不写音频指令就会得到随机的环境声——
  哪怕一句话也要写（音乐情绪、关键音效、环境底噪）。
- **单拍规则**：一个时间段 = 一个动作节拍；4–7 秒一个节拍，10–15 秒最多 3–4 个节拍；
  一段里塞两个叙事转折会劣化动作与物理一致性。
- **时长与内容量匹配**：3 秒只够一个动作，别写"转身、拔枪、开枪"三连；4 秒塞不下三个场景变化。

### 公式：**主体动作 + 运镜方式 + 环境变化 + 节奏/时长**

- 单动作、单运镜；**不要写场景切换**（切换交给镜头之间的衔接）。
- 与上一镜衔接：从上一镜的**末帧**继续动作（画布支持 last 帧作为视频节点输入）。
- 对白/音效单独交给配音（TTS）节点，不要写进视频提示词。

### 避坑清单（提示词）
1. **引用模糊**：说"参考 @图1"没用——要说参考什么（形象？运镜？动作？节奏？音色？）。
2. **指令冲突**：同一段里别同时要"固定镜头"和"环绕镜头"。
3. **内容过载**：4–5 秒塞多个场景变化 = 物理不可行，动作会糊。
4. **关键词汤**：不要"8k、masterpiece、trending"——用技术性描述（浅景深、35mm、体积光）。
5. **不连贯动作**：别写"他跑起来然后停下"——写成有过渡的流畅动作语言。
6. **忽视音频**：音效设计大幅提升成片质量。

## 五、设定集（Series Bible）维护

- **风格**：一句话定调（题材 + 年代 + 色调 + 质感）。
- **角色 / 场景 / 道具卡**：`名称 + 一句话设定 + 外观关键词`。
- 首次出现某元素时补卡；此后**引用而非重写**，保证跨集跨镜一致。
- 名字要唯一且可检索（不要"路人甲1""路人甲2"混用）。

## 六、交付前自检清单

- [ ] 剧本：开场 10 秒有钩子；结尾有悬念；对白口语化；每场有目标/阻碍/转折
- [ ] 一致性：人名/地名/道具与设定集逐字一致；角色外观描述未漂移
- [ ] 分镜：镜头数 × 时长 ≈ 目标时长；每镜一个动作；相邻镜头轴线与光线连续
- [ ] **节奏**：同一场里至少一次明显的时长对比（快切/长镜）；景别随情绪推进而不是随机
- [ ] 提示词：图片含景别/光线/构图；视频单动作单运镜；风格词全片统一；**每条视频提示词都有音频指令**
- [ ] 资产：命名含项目 + 集数 + 场次（便于检索与后期对轨）
- [ ] 成片：字幕覆盖全部对白；配音与画面同长；转场时长 ≤ 1 秒
