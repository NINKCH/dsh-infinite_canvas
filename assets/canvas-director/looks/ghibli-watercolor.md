## 成像底层
- 手绘：背景水彩纸本上色，角色赛璐璐上色后合成
- 颗粒/纸纹强度区间：`[中, 高]`，水彩纸纹理与颜料沉淀可见
- 高光滚降：极柔，`[1档, 2档]` 过曝只变淡不结块
- 暗部：**不死黑**，最暗处为暖灰绿，0 值裁剪 `[≤2%]`

<!-- slice:story shot prompt -->
## 形体与骨相
- 头身比区间：`[5.5, 6.5]`（儿童 `[4.5, 5.5]`）
- 面部圆润、五官简化，眼距略宽，非写实真人
- 手部与关节简化但比例正确，动作有生活惯性
- 衣料：棉布、围裙、背带裤，柔软起自然褶，随动作摆动延迟 `[2, 3]` 帧

<!-- slice:shot prompt assets -->
## 影调与光比
- 光比区间：`[1:2, 1:4]`
- 色温区间：`[5000K, 7000K]`，正午日光偏中性，黄昏偏 `[3200K, 4000K]`
- 光源动机：天光、窗光、树荫漏光，光源永远可解释
- 柔和低反差，阴影为彩色半透明而非灰黑
- 禁止硬边投影、禁止棚拍强闪、禁止夜景霓虹主光

<!-- slice:shot prompt assets -->
## 色彩命题
- 主调淡雅自然色：草绿、天青、米白、木褐
- 辅调小面积高饱和点缀（红裙、黄花、蓝屋顶），占比 `[5%, 15%]`
- 饱和度区间：`[低, 中]`，天空与草地可到 `[中, 高]`
- 色值：`#A8C4A2` 草绿 · `#8FB8D8` 天青 · `#F2E8D5` 米白 · `#8C6B4F` 木褐 · `#D96A4A` 点缀红
- 禁止荧光色、禁止赛博紫青、禁止整体灰蒙

<!-- slice:shot prompt assets -->
## 空气与介质
- 介质层数：`[2, 4]` 层——水汽、云、光斑、空气透视
- 云：积云有体积与边缘翻卷，云底阴影偏蓝紫
- 风：草、麦浪、衣角、发丝同向摆动，幅度 `[5°, 15°]`
- 空气透视：远景饱和降 `[15%, 30%]`，明度提 `[10%, 20%]`
- 禁止镜头污渍、禁止光柱硬切

<!-- slice:shot prompt assets -->
## 光学与镜头
- 焦段区间：`[24mm, 50mm]`，全景与中景为主
- 景深：深景深，前中后景都清晰（水彩背景不虚化）
- 桶形畸变：禁止
- 滤镜：无镜头滤镜；可叠极轻纸纹与柔光
- 禁止真实光斑、禁止失焦背景

<!-- slice:prompt assets -->
## 材质响应
- 金属：铁壶、铜锁呈哑光，高光为柔和亮斑，不反射清晰环境
- 织物：棉麻有织纹，颜料边缘略渗；湿布贴身但不起塑料光
- 皮肤：平涂 + 一层腮红，`[2, 3]` 色阶，不做高光点
- 玉石：极少出现；若出现用淡绿半透 + 白色高光条，不做折射

<!-- slice:shot prompt -->
## 特效语言
- 允许：水彩晕染扩散、颜料飞白、手绘光斑、风带动的花瓣与落叶、雨丝（细笔）
- 允许：柔和逆光光晕 `[低, 中]`
- 禁止：法术粒子、发光法阵、写实爆炸、镜头光斑
- 禁止：3D 体积雾与丁达尔光柱

<!-- slice:prompt -->
## 针对性禁项
1. 3D 渲染感：平滑渐变、圆角塑料高光
2. 硬边投影：地上出现锐利黑色影子
3. 背景虚化：水彩背景被做成浅景深
4. 高饱和动漫色：荧光绿草地、塑料蓝天空
5. 五官写实：眼睛画成真人比例与高光
6. 赛璐璐平涂背景：背景没有纸纹与颜料沉淀
7. 云画成棉花糖：无体积、无云底阴影
8. 风不同向：草往左、头发往右
9. 暗部发黑：阴影直接压成黑块
10. 光效滥用：满地发光粒子与魔法阵
11. 线条粗细一致：勾线机械均匀
