## 一句话镜头 / Lens in one line

先让风把草压倒，再让人跑起来，然后让机器飞上天——所有奇观都必须先有一个物理的、可画出来的重量。

Let the wind flatten the grass, then let someone run, then let the machine fly: every marvel must first carry a weight you can draw.

<!-- slice:story -->
## 适用场景

- 动画长片与短片：飞行、冒险、成长、少女/少年主角、魔法与现实混合的世界。
- 需要"世界本身是角色"的题材：森林、海、天空、废墟、工业城镇。
- 儿童与家庭向内容，但要求成人也能看懂。
- 飞行与机械奇观：滑翔机、飞艇、蒸汽机械、老式飞机。
- 不适用：需要真人写实质感的内容（影调应改用 realistic-cinema 并换透镜）；需要极简冷构的艺术片；需要暗黑暴力与犯罪题材。

<!-- slice:story shot prompt -->
## 反例：这不是什么 / What this lens is NOT

- 不是新海诚：新海诚的天空是**壁纸**——极端占比、光斑、高饱和、情绪由光承担，人物在中景以下几乎不动；宫崎骏的天空是**活动空间**——人要飞进去、风要吹过去、云要有体积能被穿过。新海诚让你看天空，宫崎骏让你**在天空里**。
- 不是韦斯·安德森：安德森平面化、正面机位、对称、刻意的假；宫崎骏允许纵深、不规则构图、人物在画面里跑动穿行、镜头会跟着人转弯。安德森让人摆好，宫崎骏让人跑起来。
- 不是迪士尼/皮克斯歌舞片：不靠插曲推进剧情，不靠角色说俏皮话。**情绪由动作与风承担**，对白极少且克制。
- 不是高帧率 3D 动画：这是手绘赛璐璐 + 水彩背景，允许背景有纸纹，允许角色线条略有抖动。**不要 3D 渲染感**。
- 不是奇幻设定展览：不解释魔法系统、不做世界观说明。世界就是那样，人物在里面生活。
- 不是纯儿童向：有真正的危险、真正的失去、真正的死亡暗示。**不给孩子假的安慰**。

## 叙事方法

- 世界规则**不解释**：魔法怎么运作、这个城镇为什么有这些机器，全部当作日常。观众靠观察学。
- 主角是**行动者**：她/他先做事，再想事。开场十分钟内必须有一次"她主动出发"。
- 冲突是"人 vs 环境"与"人 vs 人的选择"，不做善恶对立。**反派常常也是受害者**，或者干脆没有反派。
- 用飞行/移动作为段落单位：一次起飞、一次迫降、一次穿越。**每一次飞行都改变主角的处境**。
- 情绪不给台词，给动作：奔跑、伸手、抓住、回头看、把东西抱紧。**哭的时候不给脸大特写，给背影或手**。
- 结尾允许"失去"：某个东西永久地没了（一个人、一个地方、一种可能）。不给完整的团圆。

## 镜头语言

- 主力 24mm 与 35mm：24mm 用于飞行、大 landscape、云与天空的纵深；35mm 用于人物与环境的关系。**中景（MS/MCU）是主要叙事景别**——不是特写。
- **中景叙事**：本透镜几乎不用大特写。情绪由**整个身体的动作**承担——跑、跳、伸手、抱住。脸只在中景里出现，且表情简洁（动画的表演靠姿态，不靠微表情）。
- 机位：**跟随运动**。飞行时摄影机跟着飞、横移、俯冲；奔跑时机位与人物同速平移。这是少数明确要求"摄影机要动"的透镜。
- 构图：允许不规则。人物可以偏在一角，画面大部分是环境（天空、草、海、森林）。**环境是主角之一**。
- 风是视听主角：草、麦、树、衣服、头发、云、雨丝全部同向摆动。**每一个镜头都要考虑风**。
- 分层：前景（草/树/屋檐）、中景（人物）、背景（云/山/城市）三层，每层速度不同（前景快、背景慢），制造纵深。
- 竖幅（9:16）改写：横向的飞行改为**垂直的升降**——起飞向上升、俯冲向下降；云层上下堆叠；人物在画面下三分之一，上方全是天空与云。这是本透镜在竖幅里最自然的形态。

## 灯光与色彩

- 影调质感**默认跟随 `ghibli-watercolor` 卡**（纸本水彩背景 + 赛璐璐角色），本透镜只管怎么拍。以下为本透镜对光的取舍：
- 光源永远可解释：天光、窗光、树荫漏光、火光、灯。**没有无源的光**。
- 光比 2:1–4:1，柔。阴影是**彩色半透明**（偏蓝紫或偏绿），不是灰黑。
- 色温：正午中性（5000–7000K），黄昏偏暖（3200–4000K），夜里偏冷（月光蓝）。
- 饱和度中（角色可略高，背景淡雅自然色）。云底偏蓝紫，云顶偏暖白。
- 关键色彩：草绿 `#A8C4A2`、天青 `#8FB8D8`、米白 `#F2E8D5`、木褐 `#8C6B4F`、点缀红 `#D96A4A`。
- 禁项：不要硬边黑投影、不要荧光色、不要赛博紫青、不要整体灰蒙、不要 3D 塑料高光。

## 剪辑节奏

- ASL 2–5 秒，属于 Rapid action（0.8–2.5 秒）与 Dialogue comedy（2–5 秒）之间——**这是动画特有的节奏：比真人电影快，动作段落更碎**。
- **最短镜**：0.2–0.3 倍 ASL（0.4–1 秒），用在飞行的快速切、手部动作、机械细节、风把东西吹起的瞬间。
- **锚点镜**：每段一个 2–3 倍 ASL（8–15 秒），**必须是飞行或一次完整的环境建立**（一片草原、一座城、一次云层穿越）。这是本透镜的"呼吸"，也是观众在影院里"啊"的那一下。
- 切点动机以 **cut on action** 与 **cut on idea** 为主：切在动作中（人物起跑、飞机离地的那一刻），或切在视线的落点（她抬头，切到她看到的东西）。
- 转场：硬切为主。**允许匹配剪辑**（云的形状匹配、旋转的物体匹配、圆形的机头匹配云洞）。**不用叠化**（太慢）。
- 中位数低于均值：多数镜头 2–4 秒，靠飞行锚点镜把均值拉到 4 秒。
- **动作必须分层**：一个动作拆成 起势 → 发力 → 落点 三拍，每拍一个镜头或一个画格重点。只给一拍，动作会变糊。
- 静场：每段至少一次 2–3 秒的静场（只有风、只有云、只有草），作为动作段之前的屏息。

## 声音与音乐

- 五层里**音乐（MUS）主导**，且是**久石让式的交响/钢琴主题**：旋律明确、有主题动机、敢用大编制。
- 音乐与画面关系：**音乐先行**。主题在画面到达奇观之前就进入，用来预告而不是追认。
- 环境声是第二层，且极具体：风（不同强度与质感）、草、水、木结构吱呀、机械运转、鸟、蝉、雨。
- 风必须是**听得见的**：它有方向、有强弱、有物质（吹过草 vs 吹过帆 vs 吹过窗缝，三种完全不同的声音）。
- 对白：少、短、克制。**重要的话常常在动作里说**（边跑边说、在风里喊）。允许长时间的静默段（只有音乐与环境）。
- **静默落点：起飞之前**。飞机/飞行器要起飞的那一刻，音乐与环境全部抽空 2–3 秒（只有一次呼吸或一次金属响），然后音乐与引擎声一起砸下。这是本透镜最标志性的声音动作。
- 禁项：不要摇滚/电子配乐、不要罐头音效、不要对白密集、不要环境声掩盖音乐。

## 人物与表演

- 动画表演原则：**姿态先于表情**。人物的情绪由整个身体的姿态承担（肩膀、重心、手的位置），脸只做辅助。
- 给动画师的指令是动作节拍：「她先蹲下，手撑地，然后蹬腿站起来，站起来时头发被风带起来」。
- 表情简洁：不要复杂的微表情。**一个镜头一个情绪**，且情绪要能被一眼读出（惊讶、坚决、害怕、开心）。
- 主角特质：好奇、倔强、能吃苦、会自己解决问题。**不等待救援**。
- 调度原则：人物与环境持续互动——踩到水、被草割到、抓住绳子、被风吹得站不稳。**互动产生真实**。
- 配角是功能的：一个老人（给知识）、一个同伴（给陪伴）、一个孩子（给柔软）、一个机械师（给幽默）。

## 可迁移拍摄清单

1. 写下这个世界的规则，并决定**不解释**它（观众靠观察学）。
2. 定主角的第一次主动出发，必须在开场十分钟内发生。
3. 设计这条段落的飞行/移动：从哪里起飞、经过什么、在哪里落下；每次飞行改变什么处境。
4. 给每个镜头标注风向与强度，确认草、头发、衣服、云全部同向。
5. 画三层：前景（什么在动、速度多快）／中景（人物）／背景（云或山，速度最慢）。
6. 把动作拆成起势/发力/落点三拍，每拍定一个镜头或画格重点。
7. 定 ASL 2–5 秒、最短镜 0.4–1 秒、锚点镜 8–15 秒；段落前加 2–3 秒静场。
8. 在起飞前标出那 2–3 秒的全静音，并写明随后砸进的是什么音乐与什么机械声。

## 落地示例 / Worked example

控制场景：一个人站在一扇关着的公寓门前，手里拿着打算送出去的东西，犹豫，最后没敲门就走了。

这一拍的功能：**她来还东西，但发现门里已经住了别人**——这不是她的家了。

调度：这是老城区一栋三层公寓的顶层，走廊是露天的（外面能看到天空和电线），地面是水泥，墙是米黄色的，剥落。门是木门，但门口摆着一双陌生的鞋、一个塑料桶、一把拖把。风很大，因为走廊露天，晾着的衣服在抖。

SH1 是 24mm，从走廊另一端拍，机位与人物同高。画面三层：前景是晾着的床单（被风吹得鼓起来，快速摆动），中景是她（站在门前，手里抱着一个纸盒），背景是走廊尽头的天空与电线（云在慢慢移动）。风吹动她的头发和衣角。

关键镜头 SH2 完整规格：35mm，中景，机位跟随她一小段横移（从走廊这头走到门前）。她走着，抱着纸盒。风把床单吹到她面前，她侧身让过（这个动作是本透镜的"环境互动"）。她走到门前，看到门口那双陌生的鞋。她停住。

**这里给一个 3 秒的静场**：只有风、只有床单的拍打声、只有远处电线上的鸟叫。她低头看着那双鞋。

然后她做了一个动作：她**蹲下来**，把纸盒放在鞋旁边（不是门把手上），然后把盒子往里推了一点，让它贴着墙。站起来。回头看了一次走廊（风、床单、天空）。然后走了。

**注意：全程没有台词，没有大特写。** 情绪全部在她的姿态里：蹲下、放盒子、推一下、回头、走。

SH3 是空镜：她走后的走廊，床单还在风里翻，门前的鞋和纸盒，天空的云在动。这个镜头 10 秒。**这是本透镜的"呼吸"**。

SH4 是 24mm，从楼下往上看：走廊栏杆边，她抱着的盒子已经不在了，她在栏杆边站了一会儿，看向远处。5 秒。然后她走开。

**声音**：音乐（一段钢琴与弦乐的主题）在 SH1 开始就进入，音量中等。在 SH2 她蹲下的那一刻，音乐**停**，只剩风与床单。持续到她站起来。然后音乐重新进入（同一个主题，接上）。这个"停-续"是本透镜最典型的声音设计。

弱写法：`a girl returns a box to an old apartment, nostalgic and sad, anime style`——模型会给 3D 渲染、大眼睛特写、粉色滤镜、樱花，变成流水线日式动画。
