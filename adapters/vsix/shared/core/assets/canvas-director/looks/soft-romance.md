## 成像底层
- 数字模拟负片 + 柔焦；整体提亮一档
- 颗粒强度区间：`[低, 中]`，细颗粒（有胶片感但干净）
- 高光滚降：极柔并渗光，halation `[1档, 2档]`，窗光可整个化开
- 暗部：**不死黑**，暗部偏暖灰或偏青灰，0 值裁剪 `[≤2%]`

<!-- slice:story shot prompt -->
## 形体与骨相
- 头身比区间：`[6.5, 7.5]`，写实偏纤细
- 真人骨相 + 柔光修饰：皮肤透光，发丝逆光半透明
- 衣料：薄棉、亚麻、针织、旧牛仔裤；柔软下垂，颜色彼此调和

<!-- slice:shot prompt assets -->
## 影调与光比
- 光比区间：`[1:2, 1:4]`，全片低反差
- 色温区间：`[3800K, 6500K]`，晨昏暖金与阴天青灰交替
- 光源动机：窗、天空、台灯、夕阳；光源可解释但常在画外
- 逆光与侧逆光为常态，发丝与肩线有光边
- 禁止硬光、禁止顶光、禁止浓重阴影

<!-- slice:shot prompt assets -->
## 色彩命题
- 主调奶白与浅杏打底，占 `[40%, 60%]`
- 辅调雾蓝与灰粉，点缀暖金
- 饱和度区间：`[中, 中]`，像被阳光洗过
- 色值（源自 20 位浪漫柔光导演的真实聚合）：`#FFCC80` 杏金 · `#F19A9C` 灰粉 · `#90CAF9` 雾蓝 · `#78909C` 青灰 · `#BCAAA4` 暖灰 · `#FFFFFF` 窗白
- 禁止浓重正红、禁止深黑、禁止荧光色

<!-- slice:shot prompt assets -->
## 空气与介质
- 介质层数：`[2, 4]` 层——暖雾、光晕、尘埃、水汽
- 光晕：高光周围渗光 `[12px, 32px]`
- 允许前景遮挡物（花、帘、玻璃）虚化成色块
- 禁止冷雾、禁止烟饼浓烟

<!-- slice:shot prompt assets -->
## 光学与镜头
- 焦段区间：`[35mm, 85mm]`
- 景深：`[f/1.4, f/2.8]`，浅景深，背景融成色块
- 畸变：禁止
- 滤镜：柔焦 `[1/4档, 1/2档]`、雾镜可用
- 快门：`[1/30秒, 1/60秒]` 允许轻微拖影

<!-- slice:prompt assets -->
## 材质响应
- 金属：柔反射，高光化开
- 织物：薄织物半透光，透出身体轮廓
- 皮肤：暖底 + 颊侧粉，`[2mm, 4mm]` 次表面渗光，无油光锐点
- 花：花瓣边缘透光

<!-- slice:shot prompt -->
## 特效语言
- 允许：光晕、尘埃光路、雨丝（细）、花瓣飘落、玻璃反光
- 禁止：硬光效、粒子爆点、冷色光斑、镜头星芒

<!-- slice:prompt -->
## 针对性禁项
1. 高对比硬光：脸上的影子太重
2. 死黑：夜戏也该是暖灰或青灰
3. 浓艳正色：大红大绿大蓝
4. 冷锐数码感：全画面高清锐利
5. 暗黑系打光：把柔光拍成悬疑
6. HDR 拉清晰度：毛发与皮肤过分锐利
7. 霓虹色：任何荧光
