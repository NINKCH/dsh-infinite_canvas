## 成像底层
- 数字采集做旧成低感光胶片观感；整体欠曝半档
- 颗粒强度区间：`[低, 中]`，细颗粒，暗部略粗
- 高光滚降：硬，光源边缘干净不渗光
- 暗部：大面积近黑但保留材质纹理，0 值裁剪 `[≤8%]`

<!-- slice:story shot prompt -->
## 形体与骨相
- 头身比区间：`[6.5, 7.5]`，写实
- 真人骨相，锐利但不高清商业感；面部允许疲态、油光、胡茬
- 衣料：呢子大衣、旧西装、湿透的衬衫；哑光为主，褶皱真实

<!-- slice:shot prompt assets -->
## 影调与光比
- 光比区间：`[1:5, 1:9]`，黑位下沉但纹理可读
- 色温区间：`[3400K, 4800K]`，钠灯橙黄与荧光青灰同框对撞
- 光源动机：钠灯、信号灯、雨夜车灯、百叶窗切光
- 大面积冷色底 + 一处暖光源；禁止全画面均匀亮度
- 禁止暖调柔光、禁止金色逆光、禁止高调明亮

<!-- slice:shot prompt assets -->
## 色彩命题
- 主调冷灰蓝绿打底，占画面 `[55%, 75%]`
- 辅调深绿与钢蓝，点缀一处暗红（血、尾灯、衣服）
- 饱和度区间：`[低, 中]`，皮肤保留血色，其余抽色
- 色值（源自 20 位冷调悬疑导演的真实聚合）：`#1A232D` 夜蓝黑 · `#3D5767` 钢青 · `#30493B` 暗沼绿 · `#1D3C60` 深海蓝 · `#6D3B38` 暗血红 · `#6B7B87` 冷灰
- 禁止暖棕整体调、禁止糖果色、禁止高饱和

<!-- slice:shot prompt assets -->
## 空气与介质
- 介质层数：`[1, 2]` 层——雨或薄雾，禁止浓烟
- 雨：细密冷雨，路面反光成冷色条
- 空气干净通透，远景清晰；禁止丁达尔光柱与体积雾

<!-- slice:shot prompt assets -->
## 光学与镜头
- 焦段区间：`[35mm, 135mm]`，长焦压缩为主
- 景深：`[f/1.8, f/4]`，背景压成色块
- 畸变：禁止
- 滤镜：无柔光镜；禁星芒、禁光晕
- 快门：正常速度，禁慢门拖影

<!-- slice:prompt assets -->
## 材质响应
- 金属：湿沥青与车漆反射钠灯成橙条，反射值 `[0.4, 0.7]`
- 织物：湿呢子大衣吸光变深，雨珠挂在肩线
- 皮肤：冷调底，鼻梁与颧骨一点油光，暗部青灰
- 玻璃：雨珠挂在玻璃上，后面的人影虚成色块

<!-- slice:shot prompt -->
## 特效语言
- 允许：雨丝、路灯频闪、水面倒影、百叶窗切光
- 禁止：粒子、光阵、雾团、漂浮光点、镜头光斑

<!-- slice:prompt -->
## 针对性禁项
1. 金色黄昏逆光：把悬疑拍成浪漫
2. 高调明亮画面：整体提亮、阴影全开
3. 青橙分离模板：暗部全推青、高光全推橙
4. 暖棕怀旧滤镜：把冷调洗成温情
5. 大面积纯黑无细节：死黑糊掉材质
6. 霓虹紫青赛博色：把这个调子拍成赛博朋克
7. 美颜磨皮：脸色干净发亮
8. 浓烟雾效：把通透拍成迷雾片
