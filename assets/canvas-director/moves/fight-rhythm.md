# 打斗节奏

打斗不是"更快地打架"，是**用镜头组织给观众建立重量感**。观众记住的从来不是招式，是某一下砸下去之后身体停住的那两帧。

打斗分镜还有一条**因果硬规则**（与镜头组织同等重要）：**出招 → 对手接招/防御/闪避/受击 → 反击或追击 → 攻守转换 → 位移/空间变化 → 下一轮**。每次主要攻击都必须引发对手可见的回应，禁止站桩接招；每次攻击必须指向具体对手（写明锁定部位与轨迹方向）；接触必须写清受力与破坏；跨镜的攻势延续靠每镜 tail 里的「｜战斗态：…」传递。**禁止招式名与概括词**（"回风落雁式""释放技能""能量爆炸""华丽连招"）——只写可见的身体发力链 + 对手回应 + 物理结果。


## 实测基线

对一段 10 秒 / 300 帧的实拍打斗做了逐镜切分，读数如下——把这些数字当基准，不要凭感觉：

- **10 镜 / 10 秒，平均 1.0 秒一镜**。打斗没有想象中那么快剪。
- **最短 0.27 秒**（约 8 帧）：发力瞬间，用来制造刺痛，一镜只用一次。
- **最长 1.80 秒**（约 54 帧）：第一击接触，用来交代两人关系与武器，可长。
- **景别严格交替**：特写 → 双人中景 → 大全景 → 特写，**几乎每一镜都在换景别，没有连续两镜同景别**。
- **大全景只给两件事**：空间交代与招式高潮。其余全部落在中近景，节省信息成本。
- 结构是：建置（中景，平视）→ 接触（双人中景，长）→ 反打（过肩）→ 高潮碎切（0.5 / 0.27 / 1.6）→ 情绪长镜 → 大全景收。

## 节奏三段

| 段 | 时长占比 | 镜头数 | 景别主力 | 目的 |
|---|---|---|---|---|
| 建置 | 15–20% | 2–3 | 中景 / 中近景 | 交代站位、武器、谁先动 |
| 高潮 | 55–65% | 5–8 | 特写 / 双人中景交替 | 打击密度推上去，碎切在这里 |
| 收束 | 20–25% | 2–3 | 情绪长镜 + 大全景 | 停一下，让重量落地 |

节奏变化必须**可数**：同一段里至少出现一次明显的时长反差（例：1.8s 叙事 → 0.5s + 0.27s 快切 ×2 → 1.5s 反转 → 5s 情绪长镜）。全程 1.0 秒均匀切 = 没有节奏。

## 五条可迁移手法

### 1. 刀锋入画特写

- **做什么**：先给"武器的压迫"，再给"人"。刀尖从画面一侧入画、虚化，压向对方的脸，占据画面 1/3。
- **为什么有效**：威胁感比直接拍动作更强——观众先感到危险，再看到危险属于谁。
- **怎么拍**：大特写 / 镜头 85–135mm / 刀尖在前景虚化、脸在中景实 / 时长 0.8–1.2s / 一个镜一次。

### 2. 受力点插入镜

- **做什么**：不拍全身对打，用极低角度的局部特写承担"物理重量"——靴底、剑身抽击、缠绕的衣料、被撞的木栏。
- **为什么有效**：全身镜里动作会被压缩成小位移；局部镜可以让材质与形变占满画面，重量感来自形变。
- **怎么拍**：大特写 / 镜头 50–85mm / 贴地或贴物机位 / 时长 0.5–1.0s / 同段最多两次。

### 3. 反打过肩表现从容

- **做什么**：攻击方在前景虚化（只留后脑或肩线），防守方正面中景、从容站位、微微抬眼或微笑。
- **为什么有效**：一个镜头就把强弱关系倒过来——观众立刻知道防守方还没用力。
- **怎么拍**：过肩 / 镜头 50mm / 前景虚到只剩轮廓 / 防守方正面对焦、占画面高度 60–70% / 时长 1.0–1.8s。

### 4. 情绪停顿长镜

- **做什么**：打斗中间插一个 1.5–2 秒的低机位近景，人物贴近地面、发丝垂落、呼吸可见、微表情清晰。
- **为什么有效**：比继续加速更抓人。观众在高速段被强行减速，注意力反而被拧紧。
- **怎么拍**：近景 / 镜头 85mm / 机位贴近地面 0.3–0.5m / 时长 1.5–2s / 一镜一次，放在高潮之后。

### 5. 双色服装对位

- **做什么**：两方角色在服装上给**两个可区分的色块**（例：红 vs 墨绿），并在整场打斗中保持不换装。
- **为什么有效**：打斗镜头里角色辨识度靠色块，不是靠脸——脸在动作中永远是糊的。
- **怎么拍**：在提示词里把两方服装色固定成短语，逐镜逐字重复；光线变化时也保持相对色相不变。

## 生成时的明确边界

**这一段必须读懂，它决定了成品质量。**

本卡提供**镜头节奏与景别组织手法 + 攻防因果链**。动作要"真"，靠的是把打斗拆成**可见的身体发力链**，而不是靠招式名词。

- **不写招式名**（"回风落雁式""居合三段突"）——模型不知道怎么演名字。**但必须写可见发力链**：起始姿态/重心 → 肢体顺序（腰胯先拧、后腿蹬地、手臂后送）→ 接触 → 受力反馈 → 收势。例如不写"一记凌厉的侧踢"，写"重心压到左腿、右腿贴地横扫到髋高、@对手@ 双臂交叠上架仍被扫得后撤半步"。
- **动作词表直接取用**（源自 3D 导演台骨骼姿势的关节力学，可见且可演）：侧身沉肩重心压后腿；腰胯先拧后腿蹬地发力；单臂斜上架掌面外翻上身侧倾卸力；髋部后坐上身后仰；前腿蹬直上身前压冲刺；深蹲转体贴地横扫；单膝下沉持械直下压；抬头挺胸双臂外展蓄力；上身后折双臂散开撤步卸力；全身放倒四肢摊开。打斗镜的 motion/timeBeats 从这些**可见身体状态**里取词，不再写"挥了一下"。
- **概括词禁令**："释放技能/发动攻击/能量爆炸/高速连击"这类词模型只能演成糊动作或平移。写成画面事实：谁、哪个部位、朝哪个方向、把什么推向哪里、对方身体如何回应。
- **仍然诚实的一条**：本卡不承诺逐帧还原任何实拍片段的动作时序。要真实动作质感，两条升级路依然有效：① 打斗镜先出**发力关键帧设定图 → 图生视频（hard 首帧）**；② 3D 导演台骨骼动画摆出真实关节角度后截图作首帧/参考。但"文字写不出打斗"是旧口径，已废弃——**写足发力链 + 回应 + 物理结果，模型就能演出打斗**。
- 打斗分镜里，把文字用在**该写的地方**：景别、机位、时长、光向、服装色块、攻防因果（attack/reaction/impact/攻守归属）、打击后的身体状态（"停在半跪，右手撑地，头抬起看向对方"）。
